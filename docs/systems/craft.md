## デフォルトと違う点

- 材料が 0 個のレシピは常に作れる
- 材料の数に上限を設けていない。UI が出せるのは 4 種までで、5 種目は表示されない
- 完成品は持ち物に入らない。作業台の位置に落ちるので、拾い直す
- 材料が足りないとき、ボタンは押せる。押しても何も起きず、ログが出るだけ
- 交換画面は作業台を離れても閉じない。作業台の無い場所で押しても作らず、材料も減らない
- 倒れている間と場所を移っている間は、押しても作らない
- 材料の所持数は、持ち物が変わるたびに書き直す。開いたまま拾っても、閉じて開き直しても今の数が出る
- 持ち物と地図の入れ替えが動いているあいだは、もう一度「交換」を押しても効かない
- 原簿に値段のある品は、所持金でも買える。作れる品には「作成」、売っている品には「N コインで買う」が出て、
  両方あれば左右に並ぶ。買った品も作業台に落ちる。倒れている間・移っている間・作業台の無い場所では買えない
- 所持金が足りないと「所持金が足りません」と出て、何も起きない。材料が足りないときと違い、遊ぶ側に知らせる
- 作れない品（スライムゼリー）を開くと材料の枠は空になり、「作成」を押しても前に開いた品は作られない
- 品を選ぶまでは、説明と材料の枠と「作成」「買う」のボタンを出さない

## 相互作用

- WHEN 作った、材料が個数ぶん持ち物から減り、作業台の上に完成品が落ちる
- WHEN 買った、値段のぶん所持金が減り、作業台の上に品が落ちる（[wallet](wallet.md)）
- WHEN 交換画面を開いた、根源の UI が横から入れ替わりで出る（[roots](roots.md)）

## やらないこと

- 作るのに時間をかけること。押した瞬間に出来る
- 失敗すること。材料が足りていれば必ず出来る
- 作れるレシピを絞ること。所持や攻略度で解放されない

## 未決

- レシピが 5 つしかない。伝説の剣、俊敏の首飾り、剛力のペンダント、松明、木の柵
- 伝説の剣の材料を集めきるまでの長さが妥当か。枝もコアも、根源に 40 分ほど居て集まる見込み
- 売る品が 2 つしかない（スライムゼリーと松明）。売る品を足すと、交換画面に品のボタンも要る
- 買う場所が作業台。店を別に置くか
- 材料 5 種以上のレシピを作りたいか。作るなら UI の作り直しが要る
- 完成品を落とすのではなく直接持ち物へ入れるか。いまは作業台から離れて作ると、品は離れた作業台に落ちる。
  拾わずに拠点を出ると、拠点のシーンと一緒に消える
