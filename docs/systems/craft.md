## 用語

- **作業台** — 拠点にある、品を作る・買う所
- **交換画面** — 品を選んで、作るか買う画面

## 受け入れ条件

- 材料が 0 個のレシピは常に作れる
- 交換画面に出せる材料は 4 種まで
- 作った品も買った品も、持ち物には入らない。作業台の位置に落ちるので、拾う
- 品を選ぶまでは、説明と材料の枠と「作成」「買う」のボタンを出さない
- 原簿に値段のある品は、所持金でも買える。作れる品には「作成」、売っている品には値段を添えた「買う」が出て、両方あれば左右に並ぶ
- 作れない品を開くと材料の枠は空になり、「作成」を押しても前に開いた品は作られない
- 材料の所持数は、持ち物が変わるたびに書き直す。開いたまま拾っても、閉じて開き直しても今の数が出る
- WHEN 作った、材料が個数ぶん持ち物から減り、作業台の上に完成品が落ちる
- WHEN 買った、値段のぶん所持金が減り（[wallet](wallet.md)）、作業台の上に品が落ちる
- IF 材料が足りない THEN 「作成」は押せるが、何も起きない。遊ぶ側には知らせない
- IF 所持金が足りない THEN 「所持金が足りません」と出て、何も起きない
- 交換画面は作業台を離れても閉じない。作業台の無い場所で押しても作らず買えず、材料も所持金も減らない
- 倒れている間と場所を移っている間は、押しても作らず買えない
- 持ち物と地図の入れ替えが動いているあいだは、もう一度「交換」を押しても効かない

## やらないこと

- 作るのに時間をかけること。押した瞬間に出来る
- 失敗すること。材料が足りていれば必ず出来る
- 作れるレシピを絞ること。所持や攻略度で解放されない

## 未決

- レシピが少ない。伝説の剣、俊敏の首飾り、剛力のペンダント、松明、木の柵だけ
- 伝説の剣の材料を集めきるまでの長さが妥当か
- 売る品が少ない（スライムゼリーと松明だけ）。足すと、交換画面に品のボタンも要る
- 買う場所が作業台。店を別に置くか
- 材料 5 種以上のレシピを作るか。作るなら交換画面の作り直しが要る。持ち物が埋まったときの逃げ道（[D-34]）が先
- 完成品を落とすのではなく、直接持ち物へ入れるか。いまは作業台から離れて作ると、品は離れた作業台に落ちる。
  拾わずに拠点を出ると消える
