## 用語

- **作業台** — 拠点にある、品を作る・買う所
- **交換画面** — 品を選んで、作るか買う画面

## 受け入れ条件

### 作ると買う

| 手段 | できる品 | 押したとき | 足りないとき |
|---|---|---|---|
| 作る | レシピのある品 | 材料が個数ぶん持ち物から減り、作業台の位置に品が落ちる | 「作成」は押せるが何も起きず、知らせも出ない |
| 買う | 原簿に値段のある品 | 値段のぶん所持金が減り（[wallet](wallet.md)）、作業台の位置に品が落ちる | 「所持金が足りません」と出て、何も起きない |

- 作った品も買った品も、持ち物には直に入らない
- 材料が 0 個のレシピは常に作れる
- IF 作業台の無い場所で押した THEN 作らず買えず、材料も所持金も減らない
- WHILE 倒れている、押しても作らず買えない
- WHILE 場所を移っている、押しても作らず買えない

### 画面

| 部品 | 出すもの | 出る条件 |
|---|---|---|
| 説明と材料の枠 | 選んだ品の説明と材料 | 品を選んだあと |
| 「作成」 | — | 選んだ品が作れる品 |
| 「買う」 | 値段 | 選んだ品が売っている品 |
| 材料の所持数 | 今の数 | 持ち物が変わるたびに書き直す |

- 材料の枠に出せるのは 4 種まで
- 「作成」と「買う」の両方が出るときは左右に並ぶ
- IF 作れない品を開いた THEN 材料の枠が空になる
- IF 作れない品を開いたまま「作成」を押した THEN 前に開いた品は作られない
- 交換画面は作業台を離れても閉じない
- WHILE 持ち物と地図の入れ替えが動いている、「交換」を押しても効かない

## やらないこと

- 作るのに時間をかけること。押した瞬間に出来る
- 失敗すること。材料が足りていれば必ず出来る
- 作れるレシピを絞ること。所持や攻略度で解放されない

## 未決

- レシピが少ない。伝説の剣、俊敏の首飾り、剛力のペンダント、松明、木の柵だけ
- 伝説の剣の材料を集めきるまでの長さが妥当か
- 売る品が少ない。スライムゼリーと松明だけ。足すと、交換画面に品のボタンも要る
- 買う場所が作業台。店を別に置くか
- 材料 5 種以上のレシピを作るか。作るなら交換画面の作り直しが要る。持ち物が埋まったときの逃げ道（[D-34]）が先
- 完成品を落とすのではなく、直接持ち物へ入れるか。いまは作業台から離れて作ると、品は離れた作業台に落ちる。
  拾わずに拠点を出ると消える
