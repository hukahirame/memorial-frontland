## デフォルトと違う点

- 材料が 0 個のレシピは常に作れる
- 材料の数に上限を設けていない。UI が出せるのは 4 種までで、5 種目は表示されない
- 完成品は持ち物に入らない。作業台の位置に落ちるので、拾い直す
- 材料が足りないとき、ボタンは押せる。押しても何も起きず、ログが出るだけ

## 相互作用

- WHEN 作った、材料が個数ぶん持ち物から減り、作業台の上に完成品が落ちる
- WHEN 交換画面を開いた、根源の UI が横から入れ替わりで出る（[roots](roots.md)）

## やらないこと

- 作るのに時間をかけること。押した瞬間に出来る
- 失敗すること。材料が足りていれば必ず出来る
- 作れるレシピを絞ること。所持や攻略度で解放されない
