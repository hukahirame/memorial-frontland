## デフォルトと違う点

- 足りないときは**何も起きない**。半端に減った状態を作らない
- ちょうど同額なら払える
- 表示の文字列は正典ではない
- 表示は額が変わるたびに書き直す。払う側・受け取る側は表示に触れない

## 相互作用

- WHEN クエストの報酬 `coin` を受け取った、そのぶん増える（[quest](quest.md)）
- WHEN 死亡した、100 減る。足りなければ減らない（[player](player.md)）
- WHEN 近道で根源へ移った、20 減る。【解明】に届いた根源へは払わない。足りなければ移らない（[scene](scene.md)）
- WHEN 交換画面で品を買った、値段のぶん減る。足りなければ買えない（[craft](craft.md)）
