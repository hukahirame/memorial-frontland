## デフォルトと違う点

- **いま保存は止まっている。** `Save()` は残っていて呼べば動くが、呼ぶ者が居ない。
  Domain 分割の間の措置
- 読み込みは起動時に 1 度だけ。`SaveSystem.Awake` でファイルがあれば読む
- 保存先は 1 つ。`Application.persistentDataPath` の `.savedata.json`。枠を選べない
- 既に目的のシーンに居るときはシーンを読み直さない。読み直すと `Awake` が再入する
- 敵と設置物は「いま居るシーンのぶん」しか持たない

## 相互作用

- WHEN 読み込んだ、体力・所持金・経過秒・持ち物・立ち位置・設置物が戻る
- WHEN シーンを出た、設置物の位置が控えに書かれる（[scene](scene.md)）
- WHEN シーンへ入った、そのシーンの設置物が湧き直される

## やらないこと

- 複数の保存枠
- 自動保存
- 根源とクエストの保存。`SaveData` に欄が無い
