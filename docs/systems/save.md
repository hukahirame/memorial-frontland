## 用語

- **枠** — 保存の入れ物。5 つあり、タイトルで選ぶ
- **控え** — 場所を離れるときに書いておく、その場所の状態（置いた物・拠点に攻め込んだ敵）

## 受け入れ条件

### 書く

| 書くとき | 書き終えるのを待つか |
|---|---|
| 決まった間隔 | 待たない。遊んでいるコマを止めない |
| 設定からタイトルに戻るとき（[scene](scene.md)） | タイトルが保存を読む前に待つ |
| アプリを裏に回したとき | 待つ |
| アプリを閉じたとき | 待つ |

| 書かないあいだ | 外れたあと |
|---|---|
| 読み込んだ保存を、最初の場所で戻し終える前 | 次の間隔で書く |
| 場所を移っている最中 | 次の間隔で書く |
| 倒れているあいだ | 次の間隔で書く |

- 保存は自動で書く
- 書く中身は、書くと決めた時点のもの
- 書いている途中で落ちても、前の保存は残る
- 保存を読む前と消す前は、書き終えるまで待つ
- ブラウザ（WebGL）では、保存はそのブラウザに残る
- テストでは読みも書きもしない

### 読む

| 戻すもの | 戻すとき | 前の形の保存で欠けていたら |
|---|---|---|
| 根源の攻略度・蓄積値・核の位置（[roots](roots.md)） | 最初の場所に着く前 | — |
| クエストと受注（[quest](quest.md)） | 最初の場所に着く前 | — |
| 保留中の調査（[day](day.md)） | 最初の場所に着く前 | — |
| 拠点に攻め込んだ敵（[enemy](enemy.md)） | 最初の場所に着く前 | 数だけなら、その数だけ湧き口のまわりに出す |
| 体力・所持金・経過秒・持ち物 | 保存した場所に着いたとき | — |
| 立ち位置 | 保存した場所に着いたとき | — |
| 装備している武器 | 保存した場所に着いたとき | 始めの鉄の剣のまま |
| 置いた物の位置と向き（[scene](scene.md)） | その場所へ入ったとき | 向きが無ければ、向き 0 で置き直す |
| 木の柵の残りの耐久と、倒れているか（[outfield](outfield.md)） | その場所へ入ったとき | 満タンで立った姿で戻す |
| 根源の敵の位置と残りの体力（[enemy](enemy.md)） | 保存した根源に入ったとき | 体力が無ければ、新しく湧いた敵として出す |

- 読み込みは、起動したときと、タイトルから始めたときに 1 度だけ
- 読めない保存は捨てて、はじめから始める
- 保存のある枠で始めると、保存した場所から始まる
- 枠を分ける前の保存は、1 つめの枠に入る
- 根源の名前と危険度は保存から戻さず、作り直す
- いまは無い根源の保存は捨てる
- 装備している武器は、戻した持ち物の中のその武器を持ち直し、手の絵も替える
- IF 素手で保存した THEN 始めの鉄の剣のまま始まる
- 置いた物は、すべての場所の控えを持つ
- 根源の敵は、いま居る根源のぶんだけ持つ
- 根源の敵を戻しても、湧きの本数は変わらない（[enemy](enemy.md)）
- 拠点に攻め込んだ敵は、どこで保存しても持つ
- IF 拠点で保存した THEN 出ている敵の位置と残りの体力を書く
- IF 留守に保存した THEN 控えた敵と、留守のあいだの氾濫で来た敵を書く

### 枠

- 読み書きする枠はタイトルで選ぶ
- IF タイトルを通らずに始めた THEN 1 つめの枠を使う
- 枠には名前を付けられ、長さに上限がある
- 名前は最初の保存に入る
- IF 名前を付けなかった THEN 「データ」と枠の番号を出す

### タイトル

| 状態 | きっかけ | 次の状態 | 起きること |
|---|---|---|---|
| 最初の画面 | 何か押した | 一覧 | いちばん新しく書いた枠を選んでおく |
| 一覧 | 保存のある枠を押した | 遊ぶ画面 | 続きから始まる |
| 一覧 | 空いた枠を押した | 名前の画面（新しく） | — |
| 一覧 | 「編集」を押した | 名前の画面（編集） | — |
| 一覧 | 「もどる」か Esc | 最初の画面 | — |
| 名前の画面（新しく） | 「はじめる」か、欄で決定のキー | 遊ぶ画面 | はじめから始まる |
| 名前の画面（編集） | 「決める」か、欄で決定のキー | 一覧 | その枠の保存の名前だけが変わる。書いた時刻は変えない |
| 名前の画面（編集） | 「消す」を 1 回押した | 名前の画面（編集） | ボタンが「もう一度で消す」に変わる |
| 名前の画面（編集） | 「消す」をもう一度押した | 一覧 | その枠の保存を消して空きにする |
| 名前の画面 | 「もどる」か Esc | 一覧 | — |

- 一覧は、キーの上下で選び、決定のキーで押す
- 名前はキーボードで打つ
- スマホでは画面のキーボードが出る
- ブラウザ（WebGL）では日本語の変換が効かず、英数しか打てない

### 画面

| 部品 | 出すもの | 出る条件 |
|---|---|---|
| 最初の画面 | 「PRESS ANY BUTTON」だけ | 保存の有る無しによらない |
| 一覧 | 枠を 5 つ縦に並べる | いつも |
| 枠の段 | 枠の名前、場所（管理地か根源か）、書いた日時 | 保存のある枠 |
| 枠の段 | 枠の名前と「空き」 | 保存の無い枠 |
| 「編集」 | — | 保存のある枠 |

## やらないこと

- 何かが変わるたびに書くこと
- 保存に Space キーを使うこと
