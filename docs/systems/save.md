## デフォルトと違う点

- 保存は自動。10 秒おきにまとめて書き、アプリを裏に回したとき、閉じたとき、設定からタイトルに戻るときにも書く
- 書かないときがある。読み込んだ保存を最初の場所で戻し終える前、
  場所を移っている最中、倒れているあいだ。どれも、外れたあとの次の 10 秒で書く
- 書くときは別のファイルに書いてから差し替える。書いている途中で落ちても前の保存は残る。
  読めない保存は捨てて、はじめから始める
- ファイルに書くのは裏で順に行い、遊んでいるコマを止めない。書く中身は、書くと決めた時点のもの。保存を読む・消す前と、
  アプリを裏に回すとき・閉じるときは、書き終えるまで待つ。ブラウザ（WebGL）では、その場で書く
- 読み込みは常駐シーンを読み込んだときに 1 度だけ（起動したときと、タイトルから始めたとき）。`SaveSystem.Awake` でファイルがあれば読む。
  場所は移さず、始める側が `SaveSystem.SavedAreaId` を見てその場所から始める
- 根源とクエストは、最初の場所に着く前に戻す。保存に根源が無いときと、保存のあとで足した根源のクエストは [quest](quest.md)
- 根源は名前や危険度をコードから作り直し、保存からは攻略度・蓄積値・核の位置だけを戻す。
  作る根源から外れた Id の保存は捨てる
- 保存の枠は 5 つで、枠ごとに別のファイルに書く（`Application.persistentDataPath` の `.savedata.json`・`.savedata2.json`〜
  `.savedata5.json`）。1 は枠を分ける前と同じ名前で、前の保存はそのまま 1 に入る。読み書きする枠はタイトルで選ぶ
  （`SaveSystem.Slot`）。タイトルを通らずに始めると 1
- ブラウザ（WebGL）では、保存はそのブラウザの IndexedDB に残る（書き出しのひな形 `Assets/WebGLTemplates/MemorialFloor` が書き戻す）。
  別のブラウザや別の端末とは共有されない
- タイトルは最初に「PRESS ANY BUTTON」だけを出し、何か押すとデータの一覧になる。保存の有る無しで最初の画面は変えない。
  一覧では枠を 5 つ縦に並べ、枠の名前と、保存のある枠には場所（管理地か根源か）と書いた日時、無い枠には「空き」と出す。
  押すと、保存のある枠は続きから始まり、空いた枠は名前の画面になって、名前を入れて「はじめる」（欄で決定のキーでも）で始まる。
  一覧を開いたときは、いちばん新しく書いた枠を選んでおく（決定のキーでそのまま続きから）。キーの上下で選び、Esc で一つ前の画面へ戻る。
  「もどる」と Esc は、名前の画面から一覧へ、一覧から最初の画面へ戻る
- 枠には名前を付けられる（12 字まで）。名前は保存に入れる（`SaveData.saveName`）。付けないと「データ」と枠の番号を出す。
  はじめから始める枠の名前は、保存がまだ無いので、タイトルから始める側へ渡しておき（`SaveSystem.PendingName`）、最初の保存に入る
- 保存のある枠には「編集」が付き、名前の画面で名前を変えるか消す。名前を変えても書いた時刻は変えない。
  消すときは、1 回目に押すと「もう一度で消す」に変わり、2 回目で消して空きにする
- 名前はキーボードで打つ。スマホでは画面のキーボードが出る。ブラウザ（WebGL）では日本語の変換（IME）が効かず、英数しか打てない
- 装備している武器も保存する。読み込むと、戻した持ち物の中のその武器を持ち直し、手の絵も替わる。
  これを足す前の保存と、素手で保存したときは、始めの鉄の剣のまま
- テストでは読みも書きもしない（`SaveSystem.Enabled`）。切ったままテストを終え、再生を始めるたびに戻す
- 根源の敵は「いま居る根源のぶん」しか持たない。設置物は場所ごとの控えをすべて持つ。木の柵は残りの耐久と、倒れているかと、
  控えてから保存までの秒数も持つ（ゲームを閉じているあいだは耐久が戻らない）。これを足す前の保存の柵は、満タンで立った姿で戻る
- 保存した根源の敵は、保存した根源に入ったときにだけ戻る。位置と残りの体力を持ち、間引かずに同じ数だけ戻す。
  戻しても湧きの本数はいつもと同じ。体力を持たない前の保存の敵は、新しく湧いた敵として出す（間引かれることもある）
- 拠点に攻め込んだ敵は、どこで保存しても持つ（`SaveData.baseRaiders`）。拠点に居れば出ている敵の位置と残りの体力を、
  留守なら離れるときに控えたものと、留守のあいだの氾濫で来たもの（位置を持たず、湧き口のまわりに出る）を書く。
  前の形の保存の「拠点へ向かっている敵の数」（`SaveData.raiders`）は、その数だけ湧き口のまわりに出る敵として戻す
- 立ち位置は、保存した場所に着いたときにだけ戻す。エディタで別の場所のシーンから始めると、
  その場所の決まった地点に立つ
- 設置物はアイテム ID と位置と向きで持つ。向きを持たない前の保存の設置物は、向き 0 で置き直す

## 相互作用

- WHEN 保存があって起動した、最初の場所に着く前に、根源の攻略度・蓄積値・核の位置、クエストと受注、
  拠点に攻め込んだ敵、保留中の調査が戻る（[roots](roots.md) / [quest](quest.md) / [day](day.md) / [enemy](enemy.md)）
- WHEN 保存があって起動した、保存した場所から始まり、着いたときに体力・所持金・経過秒・
  持ち物・立ち位置が戻る（[scene](scene.md)）
- WHEN タイトルの一覧で、保存のある枠の「編集」から名前の画面を開き、「消す」を 2 回押した、その枠の保存が消えて空きになる。
  次にその枠を押すと、名前を決めてはじめから始まる
- WHEN タイトルの一覧で、保存のある枠の「編集」から名前を変えて「決める」を押した、その枠の保存の名前だけが変わる
- WHEN 場所を離れた、設置物の位置と向きが控えに書かれる（[scene](scene.md)）
- WHEN 場所へ入った、その場所の設置物が置き直される
