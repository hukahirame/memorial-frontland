## デフォルトと違う点

- 攻略度に上限が無い。100 を超えて伸びる
- 危険度はどこからも書き換えられない。生成時の値のまま表示される
- 氾濫の判定は、蓄積値を足した直後、攻略度を減らす前に行う。順序に意味がある
- 根源は同じ Id を二重に持たない
- 段階の表示は、根源の詳細を開いたときの値。開いているあいだに零時を越えても変わらない

## 相互作用

- WHEN 零時、蓄積値が増え、攻略度が 3 減る。増える量は攻略度 0 で 10、攻略度が 10 上がるごとに 1 減り、
  3 より下がらない
- WHEN 蓄積値が 100 以上、氾濫。蓄積値が 0 に戻り、MainSite へ敵が 5 体向かう。
  プレイヤーがどこに居ても MainSite に出る（[enemy](enemy.md)）
- WHEN 零時、次の零時に氾濫する根源があれば知らせる。その夜の氾濫の知らせとあわせて、1 件ずつ順に出す
- WHEN 敵を 1 体倒した、蓄積値が 3 減る（[enemy](enemy.md) が下げる）
- WHEN クエストを達成した、報酬の `progress` のぶん攻略度が上がる（[quest](quest.md)）
- WHEN 根源のシーンへ入った、拠点（スポーン地点）が置かれる。初回は候補から 1 つ選んで位置を
  `Root.SpawnX` などに控え、2 回目からは控えた位置にいちばん近い候補に置く。耐久は入るたびに戻る
- WHILE 攻略度が 50 以上、敵の湧きが抑えられる（[enemy](enemy.md)）
- WHILE 攻略度が 30 以上、湧いた敵の体力が減る（[enemy](enemy.md)）

## やらないこと

- 日数で根源が増えること。`RootCreate` は `Start` でしか呼ばれず、2 つで固定
- 根源変化。`RootTrick` は毎日 50% で呼ばれるが中身が空
