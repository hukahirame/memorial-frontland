## 用語

- **ケサ** — 通常攻撃。その場で振り下ろす
- **突き** — 体の向きへ前に出す攻撃。上下の振りが付いたものを、案内では斜め突きと呼ぶ
- **回避攻撃** — 体を回しながら奥か手前へ抜け、まわりの相手に当てる攻撃。抜けるあいだは当たらない
- **ステップ** — 体の向きと逆へ跳び退く動き
- **構え歩き** — 攻撃を押したまま離さずに、体の向きを変えずに歩くこと
- **剣の振り** — ケサと突き
- **無敵** — 当たっても体力が減らないあいだ
- **場外** — 場の範囲（[outfield](outfield.md)）の外

## 受け入れ条件

### 移動

| あいだ | できないこと |
|---|---|
| 倒れている | 歩く、跳ぶ、振る、出口と作業台に反応する |
| 場所を移っている | 歩く、跳ぶ、振る |
| 敵の湧かない物（[enemy](enemy.md)）の上に居る | 跳ぶ |
| 根源3のエスカレーターを上り下りしている | 跳ぶ |

- 移動スティックは、少ししか倒していなければ倒していないとみなす
- 移動スティックは、越えれば倒し具合によらず全速
- キーボードでは WASD で歩き、押した瞬間から全速
- 矢印キーは歩くのに使わない
- 足音は歩いているあいだだけ鳴る
- WHEN 倒れたか、場所を移り始めた、足音が止まる

### 攻撃

| 行動 | 攻撃スティックの倒し方 | キーボード | 動き |
|---|---|---|---|
| ケサ | 縦横とも小さい | Enter | その場で振り下ろす |
| 突き | 体の向きと同じ側へ大きく | Enter + 前矢印 | 体の向きへ前に出す |
| 斜め突き | 体の向きと同じ側へ大きく、縦にも大きく | Enter + 斜め前矢印 | 突きに上下の振りが付く |
| 回避攻撃 | 横は小さく、上下へ大きく | Enter + 上下矢印 | 回りながら、上なら奥へ、下なら手前へ抜ける |
| ステップ | 体の向きと逆。斜め後ろも含む | Enter + 後矢印 | 体の向きと逆へ跳び退く |
| 構え歩き | 押したまま離さない | Enter を押したまま | 体の向きを変えずに歩く |

- 前と後は、体の向きから見た向き
- 攻撃は、攻撃スティックを離したときに出る
- キーボードでは Enter を押して構え、離したときに出る
- テンキーの Enter も同じに使える
- IF 2 つの Enter を続けて押した THEN どちらも離したときに 1 度だけ出る
- キーボードの向きは、離した瞬間の矢印キーで決まる
- WHILE 矢印キーを押している、スティックを倒したときと同じく向きの印が出て剣が傾く
- IF スティックを倒している THEN 矢印キーではなくスティックの向きを使う
- 振りの終わり際に離した入力は預かり、終わってすぐ次を出す
- 終わり際より前に離した入力は捨てる

### 当たり

| 行動 | 当てる相手 | 届く範囲 | 出しているあいだの自分 |
|---|---|---|---|
| 剣の振り | 1 体。当たると、その振りではもう当たらない | ほぼ同じ奥行きの相手。突きはケサより前へ届く | 当たる |
| 回避攻撃 | 体のまわりの相手それぞれに 1 回ずつ | 剣の振りより短い | 回っているあいだは当たらない。点滅しない |
| ステップ | — | — | 当たる |

- 剣の振りが当たるのは、振りの打点を挟む短いあいだだけ
- 剣の当たりは手の剣に付いていて、振りと一緒に動く
- IF 振りかぶっているあいだに倒れたか出口に入った THEN 当たりを出さず、出ている当たりも当たらない
- 当てた相手は、自分から相手へ向かう水平の向きに飛び、少し浮く
- 回避攻撃の攻撃力・吹き飛ばし・武器の減り方は、剣の振りと同じ
- 剣の当たりは、出口にも作業台にも反応させない
- 作業台と出口は、体が重なっているときだけ反応する

### 回避攻撃の見た目

- 一瞬縮んでため、縦に伸びて小さく跳ねながら体を縦の軸で 1 回転させ、降りて縮んでから戻る
- 終わり際ほどゆっくり動く
- 回っているあいだ、足もとは地面から浮かせない
- 回っているあいだ、青みがかった半透明の残像を残す
- 回りながら剣を振り、剣の振りと同じ音を高く鳴らす

### 武器

- 攻撃力と吹き飛ばしは原簿から取る
- IF 何も装備していない THEN 素手の値を使う
- 当てた攻撃力には、剛力のペンダントのぶんを足す（[inventory](inventory.md)）
- 足した攻撃力は、敵にも核にも核の候補にも効く
- ダメージの数字は、足したあとの値で出す
- 最大耐久値が 0 の武器は耐久を持たず、振っても減らない
- 始めは、持ち物に入る鉄の剣を装備し、手の絵も鉄の剣にする
- WHEN 耐久のある武器が壊れた、素手に戻る

### 体力

| 状態 | きっかけ | 次の状態 | 起きること |
|---|---|---|---|
| 動ける | 敵に当たった（[enemy](enemy.md)） | 無敵 | 体力が敵の攻撃力ぶん減る。赤く点滅する |
| 無敵 | しばらくたった | 動ける | 髪や目が元の色に戻る |
| 動ける・無敵 | 体力が尽きた | 倒れている | 受注したクエストの対象の根源なら失敗になる（[quest](quest.md)） |
| 倒れている | しばらくたった | 無敵 | 拠点の決まった地点に立つ（[scene](scene.md)）。所持金が減る（[wallet](wallet.md)）。体力が少しだけ戻る |

- 体力の上限は、最初に場所に入ったときに決め、あとは現在値だけ引き継ぐ
- WHILE 倒れていない、時間で体力が戻り、上限で止まる
- WHILE 倒れている、当たらない
- WHILE 場所を移っている、暗転が明けるまで当たらない
- 復活のあとの無敵も、被弾のあとと同じく点滅する
- WHEN 宙で倒れた、横には動かさずに地面まで落としてから止める
- IF 落ちる先に床が無い THEN 少し待って諦め、その場で止める
- 起き上がるまでの時間は、落ちているあいだも数える

### 場外

| 出方 | 起きること |
|---|---|
| 場の外へ出た | 横へ押し戻される |
| 大きく外へ出た | 決まった地点へ連れ戻される |
| 上下に大きく離れた | 決まった地点へ連れ戻される |

- 押し戻すのは横だけで、縦の速さは残す
- 場の縁と壁のあいだの帯でも跳べる
- IF 角で 2 辺を同時に出た THEN 両方を合わせた向きへ押し戻す
- 上に離れてよい高さは場所ごとに決まり、2 階建ての根源3はほかより高い
- WHILE 場所を移っている、場外を見ない
- 場の範囲は、着いたときに入れ替わる

### 画面

| 部品 | 出すもの | 出る条件 |
|---|---|---|
| 行動の一覧 | 行動の名前とキーボードでの出し方 | いつも。攻撃スティックの左 |
| 行動の一覧 | いまの行動を赤くする | 行動しているあいだ |
| 行動の一覧 | 離すと出る攻撃を金色にする | 構えているあいだ |

## やらないこと

- 攻撃の連撃とためること
- 防御と、攻撃しない回避。当たらないあいだを持つのは回避攻撃だけ
- 空腹、疲労、状態異常
- 装備を複数の枠に持つこと。武器は 1 本だけ

## 未決

- 倒れたときに払う額と、復活時に戻る体力の根拠
- 素手の攻撃力を残すか。いまの原簿では、素手になることが無い
- 吹き飛ばしの値は仮。遊んで詰める
- 回避攻撃の値（長さ・距離・無敵・当たりの広さ）は仮。遊んで詰める。回るのは見た目だけで、当たりの範囲は向きによらない
- ジャンプはボタンを離したときに出る。着地の直前に押した分は捨てられる
