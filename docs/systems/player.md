## デフォルトと違う点

### 移動

- 移動スティックを 0.2 未満しか倒していないときは、倒していないとみなす。
  越えれば倒し具合によらず全速。キーボードは押した瞬間から全速
- キーボードでは WASD で歩く。矢印キーは攻撃の向きに使うので、歩くのには使わない
- 倒れている間と場所を移っている間は、跳ばない。ジャンプボタンも Space も効かない
- 湧く地面を探す Raycast が素通りする物（Ignore Raycast のレイヤー）の上では跳べない。接地の判定も同じ Raycast で見ている。
  根源3のエスカレーターはこのレイヤーで、上り下りのあいだは跳べない
- 足音は歩いているあいだだけ鳴る。倒れたときと場所を移るときは止まる

### 攻撃

- 攻撃は攻撃スティックを離したときに出る。当たるのは振り始めから 0.2〜0.45 秒の間だけで、
  振りのアニメの打点（約 0.32 秒）を挟む。1 体に当たると、その振りではもう当たらない
- 剣の当たりは手の剣に付いていて、振りのアニメと一緒に動く。前へ届くのは、突きで約 0.85（当たるあいだずっと前に出ている）、
  ケサで約 0.7（打点のあたりの一瞬だけ。それ以外は振りかぶった後ろの上か、振り下ろした足もと）。
  奥行きは剣の厚みの 0.2 しかなく、ほぼ同じ奥行きにいる相手にしか当たらない
- キーボードでは右Shift が攻撃スティックの代わり。押して構え、離したときに出る。向きは離した瞬間の矢印キーで決まり、
  斜めは 2 つ押す。矢印キーを押しているあいだは、スティックを倒したときと同じく向きの印が出て剣が傾く。
  スティックを倒しているときはスティックの向きを使う
- 次を出せるのは、ケサは振り始めから 0.6 秒、突きは 0.7 秒。振りのアニメはどちらも 0.5 秒で、残りは構えに戻った姿で待つ
- 振りの終わり際 0.25 秒に離した入力は預かり、終わってすぐ次を出す。それより前の入力は捨てる
- 倒れている間と場所を移っている間は、離しても振らない。歩けないのと同じ。
  振りかぶっているあいだに倒れたり出口に入ったりしたら当たりは出さず、出ている当たりも当たらない
- 当てた相手は、自分から相手へ向かう水平の向きに飛ぶ。強さの 3 分の 1 だけ浮く
- 攻撃スティックの倒し方で 4 種類に分かれる。閾値はどれも 0.5
  - 体の向きと**同じ側**へ 0.5 より大きく倒す → 突き
  - 縦横とも 0.5 未満 → ケサ
  - 横は 0.5 未満で、上下へ 0.5 より大きく倒す → 回避攻撃
  - 体の向きと逆（斜め後ろも含む） → ステップ
- 閾値ちょうどはステップになる。突きと回避攻撃は「超える」を、ケサは「下回る」を求めるため、
  どの条件にも当たらない
- 突きの上下の振りは、縦が 0.5 を超えたときだけ出る。中間では出ない。上下の振りが付く突きを、案内では斜め突きと呼ぶ
- 回避攻撃は、体を縦の軸で 1 回転させながら、上なら奥へ、下なら手前へ 0.7 秒で 1.5 抜ける。終わり際ほどゆっくり動く。
  回り始めから 0.62 秒は当たらない（被弾のあとの無敵と違って点滅しない）。回り始めて 0.16〜0.55 秒のあいだは、
  体のまわり半径 0.5（剣の振りが前へ届く、ケサの約 0.7・突きの約 0.85 より短い）にいる相手に、それぞれ 1 回ずつ当てる。
  剣の振りと違って 1 体では止まらない。攻撃力・吹き飛ばし・武器の減り方は剣の振りと同じ
- 回避攻撃の見た目は、一瞬縮んでため、縦に伸びて小さく跳ねながら回り、降りて縮んでから戻る。縮み伸びのあいだも足もとは
  地面から浮かせない。回っているあいだに、青みがかった半透明の残像を等しい間隔で 3 枚残し、0.2 秒で消す。残像は正面を向いた姿で写す
  （回っている途中の姿は、横向きで細い線になったり裏返ったりして、重なると形が崩れて見えた）。回りながら剣を振り、剣の振りと同じ音を高く鳴らす
- 攻撃を押したまま離していないあいだ（スティックに触れているか、右Shift を押しているあいだ）は、体の向きを変えずに歩ける。
  案内では構え歩きと呼ぶ
- 攻撃スティックの左に、行動の名前と出し方を小さく並べる。通常攻撃（ケサ）は F、突きは F + 前矢印、
  斜め突きは F + 斜め前矢印、ステップは F + 後矢印、回避攻撃は F + 上下矢印、構え歩きは F hold。前と後は体の向きから見た向き。
  いまの行動（振っている攻撃、構えているあいだは構え歩き）を赤く、構えているあいだは離すと出る攻撃を金色にする
  （[staging](staging.md)）

### 武器

- 何も装備していないときの攻撃力は 40。これは元の `static` の初期値がそのまま
  効いていた値。吹き飛ばしは 2
- 攻撃力と吹き飛ばしは原簿から取る。表示名では決めない
- 当てた攻撃力には、持ち物の剛力のペンダントのぶん（1 つにつき 10）を足す。敵にも根源の核と候補にも効き、
  出るダメージの数字も足したあとの値になる（[inventory](inventory.md)）
- 最大耐久値が 0 の武器は耐久を持たず、振っても減らない。いまの原簿では全部 0
- 始めは、持ち物に入る鉄の剣を装備している。手の絵も鉄の剣で始まる。
  素手になるのは、耐久のある武器が壊れたときだけ（いまの原簿では起きない）
- 装備している武器は、持ち物のその枠に「装備中」の札で示す（[inventory](inventory.md)）。保存もし、読み込むと持ち直す（[save](save.md)）

### 体力

- 正典は Domain の `Health`。UI の Slider は表示
- 上限を決めるのはシーンに入ったとき 1 度だけ。2 回目以降は現在値だけ引き継ぐ
- 時間で自然に回復する。1 秒ごとに 2。倒れている間は回復しない。それ以外に条件は無く、上限で止まる
- 被弾してから 1 秒は無敵で、続けて当たっても減らない。赤い点滅もこの間だけ続き、
  終わると髪や目は元の色に戻る。倒れている間は当たらない
- 場所を移っているあいだ（暗転して明けるまで）は当たらない。動けないため。倒れて拠点へ戻される途中も同じ
- 倒れて戻ったあとは、動けるようになってから 3 秒は当たらない。被弾のあとと同じく点滅する。
  戻る地点が攻め込んだ敵のうろつく範囲の内にあり、戻ったときの体力ではスライムの一撃に耐えないため
- 宙で倒れたら、横には動かさずに地面まで落としてから止める。床の無い所では 2 秒で諦めてその場で止める。
  倒れてから起き上がるまでの 5 秒は、落ちているあいだも数える
- 作業台と出口は、体の固い当たりが重なっているときだけ数える。剣や視界確保の当たりもプレイヤーの子で、
  その出入りもプレイヤーに届くため、区別しないと剣を振っただけで出口に入ったり、作業台のボタンが消えたりする。
  倒れているあいだは体の当たりを切るので、出口にも作業台にも反応しない

### 場外

- 場の外へ出ると押し戻される。0.4 より外へ出ると原点へ連れ戻される。押し戻すのは横だけで、
  跳んだ勢いと吹き飛ばしの縦の速さは残す。場の縁と壁のあいだの帯でも跳べる
- 下へ 4 を超えて離れても連れ戻される。上は場所ごとの高さを超えたら連れ戻す。ふつうは 4 で、2 階建ての根源3は 8
  （上の階の床 4 から、ほかの場所と同じだけ上）
- 角で 2 辺を同時に出たときは、両方を合わせた向きへ押し戻す
- 場所を移っているあいだ（暗転して明けるまで）は見ない。場の範囲は着いたときに入れ替わる

## 相互作用

- WHILE 死んでいない、1 秒ごとに体力が 2 戻る
- WHEN 敵に当たった、無敵でなければ体力が敵の攻撃力ぶん減り、1 秒の無敵に入る（[enemy](enemy.md)）
- WHEN 体力が 0 になった、死亡。5 秒後に復活する
- WHEN 復活した、所持金が 100 減り、体力が上限の 5% に戻り、原点へ立つ。動けるようになってから 3 秒は当たらない
  （[wallet](wallet.md) / [enemy](enemy.md)）
- WHEN 倒れた、どこで倒れても MainSite の決まった地点へ戻される（[scene](scene.md)）
- IF 受けているクエストの根源で倒れた THEN 戻ったときに報酬 UI が失敗として出る。ほかの場所で倒れても失敗にはならない
  （[quest](quest.md)）
- WHILE 俊敏の首飾りを所持、移動速度が上がる（[inventory](inventory.md)）
- WHILE 剛力のペンダントを所持、攻撃力が上がる（[inventory](inventory.md)）
- WHEN 使い道が「食べる」のアイテムを使った、回復量ぶん体力が戻る（[inventory](inventory.md)）
- WHEN 武器が壊れた、素手に戻る。いまの原簿では起きない
- WHEN 木の柵へ向かって跳んだ、柵を越えられる。歩くだけでは通れない（[outfield](outfield.md)）
- WHEN 剣が木の柵に当たった、何も起きない。柵は削れず、止めも揺らしもしない（[outfield](outfield.md)）
- WHEN 木の柵から 0.8 以内に入った、Allmaity ボタンに「柵を壊す」が出る。押すと、手の届く柵のうちいちばん近いものを壊す。
  手の届く柵が無くなったら、ボタンは消える（[outfield](outfield.md)）
- WHEN 木の柵を置いた、絵が向いている側（`Player2.Side`）に、奥行きに沿って立つ。止まっても向きは残る（[outfield](outfield.md)）
