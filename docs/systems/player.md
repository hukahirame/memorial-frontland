## デフォルトと違う点

### 攻撃

- 攻撃スティックの倒し方で 3 種類に分かれる。閾値はどれも 0.5
  - 体の向きと**同じ側**へ 0.5 より大きく倒す → 突き
  - 縦横とも 0.5 未満 → ケサ
  - 体の向きと逆、または上下だけ → ステップ
- 閾値ちょうどはステップになる。突きは「超える」を、ケサは「下回る」を求めるため、
  どちらの条件にも当たらない
- 突きの上下の振りは、縦が 0.5 を超えたときだけ出る。中間では出ない

### 武器

- 何も装備していないときの攻撃力は 40。これは元の `static` の初期値がそのまま
  効いていた値
- 攻撃力と吹き飛ばしは原簿から取る。表示名では決めない
- 最大耐久値が 0 の武器は耐久を持たず、振っても減らない。いまの原簿では全部 0

### 体力

- 正典は Domain の `Health`。UI の Slider は表示
- 上限を決めるのはシーンに入ったとき 1 度だけ。2 回目以降は現在値だけ引き継ぐ
- 時間で自然に回復する。5 秒ごとに 1。回復に上限以外の条件を付けていない

### 場外

- 場の外へ出ると押し戻される。0.4 より外へ出ると原点へ連れ戻される
- 上下に 4 を超えて離れても連れ戻される
- 角で 2 辺を同時に出たときは、両方を合わせた向きへ押し戻す

## 相互作用

- WHILE 死んでいない、5 秒ごとに体力が 1 戻る
- WHEN 敵に当たった、体力が敵の攻撃力ぶん減る（[enemy](enemy.md)）
- WHEN 体力が 0 になった、死亡。5 秒後に復活する
- WHEN 復活した、所持金が 100 減り、体力が上限の 5% に戻り、原点へ立つ
  （[wallet](wallet.md)）
- IF 死亡したシーンが MainSite でない THEN MainSite へ戻され、報酬 UI が失敗として出る
  （[quest](quest.md) / [scene](scene.md)）
- WHILE 俊敏の首飾りを所持、移動速度が上がる（[inventory](inventory.md)）
- WHEN 使い道が「食べる」のアイテムを使った、回復量ぶん体力が戻る（[inventory](inventory.md)）
- WHEN 武器が壊れた、素手に戻る。いまの原簿では起きない

## やらないこと

- 攻撃の連撃とためること
- 防御と回避
- 空腹、疲労、状態異常
- 装備を複数の枠に持つこと。武器は 1 本だけ
