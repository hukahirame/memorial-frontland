## デフォルトと違う点

- シーンは 2 段になっている。常駐シーン `Core` にプレイヤー・UI・`GameManager`・移動の入口を置き、
  拠点と根源のシーンを Additive で差し替える。`DontDestroyOnLoad` は使わない
- 場所を移るのは `AreaTravel` の 1 か所だけ。出口・倒れたとき・始めるとき・保存からの再開がすべてここを通る
- 今いる場所は `AreaTravel.Where` が持つ。場所の Id はシーン名で、根源の場所は根源の Id と同じ名前。
  この対応を知っているのは `TravelRule` だけ
- 場所のシーンはルートに `Area` を 1 つ持つ。拠点か根源か、入口、決まった地点、場の範囲
- 場所は拠点、根源1、根源2、根源3 と一列に並び、出口は隣の場所へ通じる。並びは拠点のあとに根源を作った順。
  出口は手前（拠点の側）と奥の 2 種類で、端より先へは行けない。受注にかかわらず通れる
- 出口に歩いて入るだけで移る。ボタンは出さない
- どの出口にも、行く向きを指す木の矢印の看板が立つ。手前へ戻る出口は左、奥へ進む出口は右を指す。
  根源3の戻る出口は左の壁の扉で、遊ぶときのカメラからは横から見えて暗い筋にしか見えないので、看板を扉の前に立てる。
  根源2の奥の出口と根源3の看板は `Root3Builder` が立てる
- 拠点からは、近道でどの根源へも直に行ける。地図で根源の詳細を開くと「近道で向かう」が出て、
  押すたびに 20 コインを払い、その根源の入口に立つ。その根源の今の攻略度が【解明】（30）に届いていれば無料（[roots](roots.md)）。
  払う額を見せてから移るので、出口と違ってボタンで押す。見せる額は詳細を開いたときの攻略度で決める。
  開いたまま零時を越えるなどして押したときの額が見せた額と違えば、払わず移らず、新しい額を出し直して
  「近道の料金が変わりました」と出す。払えなければ移らず「所持金が足りません」と出す。詳細を開いたまま拠点を出てから押しても移らない
- 根源からは、地図の「拠点へ戻る（無料）」で、拠点の決まった地点へ無料で戻れる。受けたクエストの対象の根源に
  居るあいだは使えず、ボタンは「クエスト中は戻れません」になって押せない。核を壊したあとも、歩いてその根源を出る。
  通り道の根源からは使える
- 手前の場所から来たら入口に、奥の場所から来たら奥の入口に立つ。出口が 1 つの場所は、どちらから来ても入口に立つ。
  向きは歩いてきたまま。始めたときと倒れたあとは決まった地点に立つ。
  拠点の決まった地点は (-2, 0.65, -2)。根源には無く、入口に立つ
- 移るときは画面を黒で覆い（`ScreenVeil`）、覆っているあいだに裏で読み込む。BGM も一緒に下げて、
  着いた場所の曲で上げる。覆い始めてから開け終わるまで、プレイヤーは動かない
- 始めは画面を覆っておき、最初の場所に着いてから開ける
- 着いたシーンは、そのシーンの `Start` より前に有効になる。`Start` で生んだ物はその場所に入る
- 着いたときの処理は `SceneStarter` が受け、拠点か根源かで分かれる
- 置いた物は場所ごとにアイテム ID と位置と向きで控える（`PlacedObjects`）。離れるときに書き、入るときに置き直す。
  木の柵は、残りの耐久と倒れているかと控えた時刻も控え、離れていたあいだに戻るぶんを足して戻す（[outfield](outfield.md)）
- エディタで場所のシーンから再生すると、常駐シーンが自動で足され、その場所の決まった地点（根源なら入口）から始まる
- BGM は拠点だけ 2 曲から 50% で選ぶ

## 相互作用

- WHEN 場所を離れた、置いた物の位置と向きが控えに書かれる（[save](save.md)）
- WHEN 根源へ入った、核の位置が決まり、ジャンプボタンが繋ぎ直される。受けたクエストの根源ならクエストが始まる。
  成功が決まっていれば、報酬を受け取って大きい文字で知らせる（[roots](roots.md) / [quest](quest.md)）
- WHEN 場所を離れた、受けたクエストを達成したままその根源を出たなら、成功が決まる（[quest](quest.md)）
- WHEN 拠点へ入った、報酬 UI のフラグが立っていれば報酬 UI が出る（[quest](quest.md)）
- WHEN 場所へ入った、体力の表示と場の範囲が繋ぎ直される（[player](player.md)）
- WHEN 倒れた、拠点の決まった地点へ戻る。拠点で倒れたときは読み直さず、暗転して立ち位置だけ戻す（[player](player.md)）
- WHEN 近道で移った、所持金が 20 減り（【解明】に届いた根源へは払わない）、根源の詳細と地図が閉じる（[wallet](wallet.md)）
- WHEN 拠点への近道で根源を出た、歩いて出たときと同じく、成功が決まっていれば着いたときに受け取る（[quest](quest.md)）

## やらないこと

- シーンの動的生成。用意された場所のシーンを行き来する
- 出口に入る前からの先読み。Unity のシーンの先読みは途中で取り消せず、出口の前で引き返すと読んだ分が無駄になる
- 境目を無くすこと（歩いたまま隣の場所へ入る）。場所ごとにシーンを差し替えるため
