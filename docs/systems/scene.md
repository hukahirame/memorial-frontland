## 用語

- **場所** — 拠点と根源。拠点、根源1、根源2、根源3 と一列に並ぶ
- **出口** — 隣の場所へ通じる所。手前（拠点の側）と奥の 2 種類
- **入口・奥の入口** — 手前から来たとき、奥から来たときに立つ所
- **決まった地点** — 拠点で、始めたときと倒れたあとに立つ所
- **近道** — 拠点と根源を、出口を通らずに直に行き来する手段

## 受け入れ条件

### 行き来

- 出口は隣の場所へ通じる。端より先へは行けない。受注にかかわらず通れる
- 出口に歩いて入るだけで移る。ボタンは出さない
- どの出口にも、行く向きを指す木の矢印の看板が立つ。手前へ戻る出口は左、奥へ進む出口は右を指す。
  根源3の戻る出口は左の壁の扉で、看板は扉の前に立つ
- 手前の場所から来たら入口に、奥の場所から来たら奥の入口に立つ。出口が 1 つの場所は、どちらから来ても入口に立つ。
  向きは歩いてきたまま
- 始めたときと倒れたあとは、拠点の決まった地点に立つ
- 出口・近道・倒れたとき・始めるとき・保存からの再開は、どれも同じ移り方をする
- 移るときは画面を黒で覆い、覆っているあいだに裏で読み込む。BGM も一緒に下げて、着いた場所の曲で上げる。
  覆い始めてから開け終わるまで、プレイヤーは動かない
- 始めは画面を覆っておき、最初の場所に着いてから開ける
- BGM は拠点だけ、2 曲のどちらかを選んで鳴らす
- WHEN 倒れた、拠点の決まった地点へ戻る。拠点で倒れたときは読み直さず、暗転して立ち位置だけ戻す（[player](player.md)）
- 置いた物は場所ごとに控える。離れるときに位置と向きを書き、入るときに置き直す。木の柵は耐久も戻す（[outfield](outfield.md)）
- エディタで場所のシーンから再生すると、その場所の決まった地点（根源なら入口）から始まる

### 近道

- 拠点からは、どの根源へも直に行ける。地図で根源の詳細を開くと「近道で向かう」が出て、押すと料金を払ってその根源の入口に立つ（[wallet](wallet.md)）。
  その根源の今の攻略度が【解明】に届いていれば無料（[roots](roots.md)）
- 払う額を見せてから移る。見せる額は詳細を開いたときの攻略度で決める
- IF 押したときの額が見せた額と違う THEN 払わず移らず、新しい額を出し直して「近道の料金が変わりました」と出す
- IF 払えない THEN 移らず「所持金が足りません」と出す
- 詳細を開いたまま拠点を出てから押しても移らない
- WHEN 近道で移った、根源の詳細と地図が閉じる
- 根源からは、地図の「拠点へ戻る（無料）」で、拠点の決まった地点へ無料で戻れる。通り道の根源からも使える
- IF 受けたクエストの対象の根源に居る THEN 拠点への近道は使えない。ボタンは「クエスト中は戻れません」になって押せない。
  核を壊したあとも、歩いてその根源を出る（[quest](quest.md)）
- WHEN 拠点への近道で根源を出た、歩いて出たときと同じに扱う。成功が決まっていれば着いたときに受け取る（[quest](quest.md)）

### 設定とタイトル

- 遊ぶ画面の右上、持ち物のボタンの真下に設定の歯車のボタンがある（キーは Esc）。押すと設定の窓が開き、開いているあいだは
  ゲームが止まる（時間・敵・一日の巡り）。後ろは暗くなり、後ろのボタンやスティックは押せない。移っている途中は開かない
- 設定の窓には「タイトルに戻る」と閉じるボタンがある
- WHEN 「タイトルに戻る」を押した、書いてよいときなら保存してからタイトルが開く。移っている途中と倒れているあいだは書かず、
  最後の自動の保存が残る（[save](save.md)）
- タイトルは開くたびに、遊びの状態を起動した直後と同じに戻す。タイトルから別の枠や空いた枠で始めても、前の遊びは混ざらない

## やらないこと

- シーンの動的生成。用意された場所のシーンを行き来する
- 出口に入る前からの先読み
- 境目を無くすこと（歩いたまま隣の場所へ入る）

## 未決

- 近道の料金が、調査の報酬（[quest](quest.md)）に対して安いか高いか
- 根源から別の根源への近道は無い。拠点を経るか、出口を通る
