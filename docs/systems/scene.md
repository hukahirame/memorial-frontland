## 用語

- **場所** — 拠点と根源。拠点、根源1、根源2、根源3 と一列に並ぶ
- **出口** — 隣の場所へ通じる所。手前（拠点の側）と奥の 2 種類
- **入口・奥の入口** — 手前から来たとき、奥から来たときに立つ所
- **決まった地点** — 拠点で、始めたときと倒れたあとに立つ所
- **近道** — 拠点と根源を、出口を通らずに直に行き来する手段

## 受け入れ条件

### 出口

| 出口 | 看板の矢印 |
|---|---|
| 手前へ戻る出口 | 左 |
| 奥へ進む出口 | 右 |

- 出口は隣の場所へ通じ、端より先へは行けない
- 出口は、歩いて入るだけで移る
- 出口は受注にかかわらず通れる
- どの出口にも、行く向きを指す木の矢印の看板が立つ
- 根源3の戻る出口は左の壁の扉で、看板は扉の前に立つ

### 立つ所

| 着き方 | 立つ所 |
|---|---|
| 手前の場所から出口で来た | 入口 |
| 奥の場所から出口で来た | 奥の入口 |
| 出口が 1 つの場所へ来た | 入口 |
| 拠点から近道で来た | その根源の入口 |
| 根源から近道で戻った | 拠点の決まった地点 |
| 始めた | 拠点の決まった地点 |
| 倒れた（[player](player.md)） | 拠点の決まった地点 |
| 保存から再開した | 保存した立ち位置（[save](save.md)） |
| エディタで場所のシーンから再生した | その場所の決まった地点。根源なら入口 |

- 出口で来たときの向きは、歩いてきたまま

### 移り方

- どの着き方でも、同じ移り方をする
- 移るときは画面を黒で覆い、覆っているあいだに裏で読み込む
- BGM は覆うのに合わせて下げ、着いた場所の曲で上げる
- WHILE 覆い始めてから開け終わるまで、プレイヤーは動かない
- 始めは画面を覆っておき、最初の場所に着いてから開ける
- IF 拠点で倒れた THEN 読み直さず、暗転して立ち位置だけ戻す
- BGM は拠点だけで、2 曲のどちらかを選んで鳴らす

### 置いた物

- WHEN 場所を離れた、置いた物の位置と向きを、場所ごとに控える
- WHEN 場所に入った、控えた物を置き直す

### 近道

| 近道 | 使える所 | 料金 | 着く所 |
|---|---|---|---|
| 根源へ | 拠点 | 払う（[wallet](wallet.md)）。攻略度が【解明】に届いていれば無料（[roots](roots.md)） | その根源の入口 |
| 拠点へ | 根源。通り道の根源でも | 無料 | 拠点の決まった地点 |

- 根源への近道は、払う額を見せてから移る
- 見せる額は、根源の詳細を開いたときの攻略度で決める
- IF 押したときの額が見せた額と違う THEN 払わず移らず、新しい額を出し直す
- IF 払えない THEN 移らない
- IF 根源の詳細を開いたまま拠点を出てから押した THEN 移らない
- WHEN 根源への近道で移った、根源の詳細と地図が閉じる
- IF 受注したクエストの対象の根源に居る THEN 拠点への近道は使えない（[quest](quest.md)）
- 核を壊したあとも、拠点への近道は使えないまま
- WHEN 拠点への近道で根源を出た、歩いて出たときと同じに扱う（[quest](quest.md)）

### 設定の窓

| 状態 | きっかけ | 次の状態 | 起きること |
|---|---|---|---|
| 閉じている | 歯車のボタンか Esc を押した | 開いている | ゲームが止まる（時間・敵・一日の巡り）。後ろが暗くなる |
| 開いている | 閉じるボタンを押した | 閉じている | ゲームが動き出す |
| 開いている | 「タイトルに戻る」を押した | タイトル | 書いてよいときなら保存する（[save](save.md)） |

- WHILE 場所を移っている、設定の窓は開かない
- WHILE 設定の窓が開いている、後ろのボタンとスティックは押せない
- IF 倒れているあいだに「タイトルに戻る」を押した THEN 書かず、最後の自動の保存が残る
- タイトルは開くたびに、遊びの状態を起動した直後と同じに戻す

### 画面

| 部品 | 出すもの | 出る条件 |
|---|---|---|
| 設定の歯車のボタン | 遊ぶ画面の右上、持ち物のボタンの真下 | いつも |
| 設定の窓 | 「タイトルに戻る」と閉じるボタン | 開いているあいだ |
| 「近道で向かう」 | 払う額 | 拠点で、地図から根源の詳細を開いたとき |
| 「拠点へ戻る（無料）」 | — | 根源で地図を開いたとき |
| 「クエスト中は戻れません」 | 押せないボタン | 受注したクエストの対象の根源に居るあいだ |
| 知らせ「近道の料金が変わりました」 | — | 押したときの額が見せた額と違ったとき |
| 知らせ「所持金が足りません」 | — | 近道の料金を払えなかったとき |

## やらないこと

- シーンの動的生成。用意された場所のシーンを行き来する
- 出口に入る前からの先読み
- 境目を無くすこと（歩いたまま隣の場所へ入る）
- 出口にボタンを出すこと

## 未決

- 近道の料金が、調査の報酬（[quest](quest.md)）に対して安いか高いか
- 根源から別の根源への近道は無い。拠点を経るか、出口を通る
