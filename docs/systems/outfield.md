## デフォルトと違う点

- 場の範囲はシーンが `Vector4` に XL, XS, ZL, ZS の順で詰めて持っている。
  どの成分がどの辺かを知っているのは `Exposition` 1 か所だけ
- 木の枝は切って落とすのではなく、**勝手に落ちてくる**。最初は 10〜20 秒後、
  以降は 20〜36 秒ごと
- 落ちる場所は範囲内で毎回引き直す。高さ 5 から落ちる
- 落ちているものは触れると拾う。持ち物が一杯なら落ちたまま残り、空いたあとは触れたままでも拾う
- 拾えるものの名前は、スプライトの名前で決まる。原簿の ID と一致している必要がある
- 地形は文字の地図に書ける（下の「地図」）。地図から Cube を組むのはエディタの中だけ
- Root1 の地形は `Root1.txt` と同じ形をしている。シーンの Cube は手で置いたままで、
  地図から組み直してはいない。地図と食い違うと `FieldTerrainTests` が落ちる
- 地図が持つのは見えている地形だけ。隠したままの Cube（Root1 のレーン B と C、壁）は入れていない

## 木の柵

作業台で作り、持ち物から置く（[craft](craft.md) / [inventory](inventory.md)）。見た目は森の素材集の柵（`Resources/Fence_obj.prefab`）。

- 敵を通さない。プレイヤーも歩いては通れないが、跳べば越えられる。当たりの高さは見た目と同じ 0.58 で、
  プレイヤーの跳び（足もとが 0.8 ほど上がる）は越え、スライムの跳び（0.2 ほど）は越えない
- 足元ではなく、主人公の絵が向いている側（右か左）に、いつも奥行きに沿って立つ。絵は左右にしか向かないので、
  奥か手前へ歩いたあとでも、見えている向きの側に立つ
- 1 マス 0.75 の格子の線の上に、2 マス（1.5）の長さで立つ（`FenceRule`）。向いている側で、体から離れた最初の線に
  立てるので、体から 0.4〜1.15 先に立つ。端が格子の点にそろうので、奥行きに沿って並べると端がつながる。
  格子は場所によらず原点からの 1 マス。マスの大きさを変えるときは、柵の prefab の当たりの長さと絵の大きさも同じ比で変える
- 地面が無い所と、足元から 0.5 より高い所や低い所には立てない。ほかの柵や、壁・岩・テントなど動かない物に
  重なる所にも立てない（見えない壁も含む）。端と角で触れ合うのは重なりとみなさない。敵と落とし物は重なっていても立て、
  柵が押しのける。立てられなければ「ここには置けません」と出て、持ち物は減らない
- 耐久は 200。敵がぶつかっているあいだは 1 秒ごとに敵の攻撃力のぶん削れる。剣では削れない（剣は素通りする）。
  削れるほど暗くなり、ぶつかられると揺れて音が鳴る
- 柵の上に、残りの耐久をゲージで出す（数字は出さない）。いつも出し、カメラに正面を向ける。
  ゲージは立っているあいだ緑、倒れているあいだ橙
- 最後に削られてから 3 秒たつと、1 秒に 1 ずつ耐久が戻る
- 耐久が尽きると、根元を軸にぶつかった敵と反対の側へ倒れ、すぐ通れるようになる。倒れているあいだは削られず、
  寝たまま耐久が戻り、上限の 4 分の 1（50）を超えると起き上がってまた通さなくなる（尽きてから 53 秒ほど）。
  削られても尽きていない柵は、4 分の 1 以下でも立っている。
  起き上がったときに重なっていた敵やプレイヤーは押し出される。倒れた柵の上には、新しい柵を立てられない
- 柵から 0.8 以内に寄ると、Allmaity ボタンに「柵を壊す」が出る。押すと、手の届く柵のうちいちばん近いものが
  膨らんでから縮んで消える。何も戻らない。倒れた柵も壊せる
- 置いた柵は、松明と同じく場所ごとに控えて置き直す。向きと、残りの耐久と、控えた時刻も控える（[scene](scene.md)）。
  離れていたあいだも耐久は戻り、戻ったときに、離れていた秒数ぶん戻した耐久で置き直す。離れる直前に削られていても、
  離れた時点から 3 秒待って数える。保存には控えてからの秒数を書くので、ゲームを閉じているあいだは数えない

## 地図

場所のシーンと同じ名前で `Assets/_Project/Data/Fields/` に置く（Root1 なら `Root1.txt`）。
記号ごとの素材と当たりの大きさは `Assets/_Project/Data/Fields/FieldPalette.asset` にまとめる。

- 1 文字が 1 マス。マスの一辺は Cube の一辺と同じで、`cell` に書く
- 上の行ほど奥（z が大きい）、左の列ほど x が小さい。`origin` は左上のマスの中心（x z）
- `top 高さ` に続く行が 1 枚の層で、上面がその高さにそろう Cube を並べる。空行で層が終わる
- `.` は何も置かない。同じ高さの層を 2 枚書くと、同じ場所に Cube が 2 つ重なる
- どの層も行の数と幅をそろえる。そろわなければ、何行目かを添えて読むのを断る
- マスに乗らない Cube は `piece 記号 x y z` の 1 行で書く。位置は中心で、向き（度）の x y z を足してよい
- `#` から行の終わりまでは注釈

```
cell 3
origin -22.5 2.5

top 0
ddddd
.ddd.

piece d 6.5 -2.05 -5.55 60 0 0
```

- 組んだ Cube の名前には `Cube` が入る。視界確保（`ViewSecurer`）が名前の部分一致で薄くする相手を探すため
- Root1 の `D` は土で、当たりだけが奥へ 1 マス伸びる。左右の端の見えない壁になっている
- 撮り比べはメニューの Tools/Field/Compare Maps With Scenes。シーンをプレビューで開き、置いてある Cube と
  地図から組んだ Cube を同じカメラ（プレイヤーのカメラと同じ位置関係）で撮って、違う画素を数える。
  シーンは保存せず、絵は `Temp/FieldShots/` に出る

## 相互作用

- WHEN 落ちているものに触れた、持ち物へ入る（[inventory](inventory.md)）
- IF 持ち物に空きが無い THEN 拾わず、その場に残る
- WHEN 場の外へ出た、押し戻される（[player](player.md) / [enemy](enemy.md)）
- WHEN 根源のシーンへ初めて入った、拠点の位置が候補から選ばれる（[roots](roots.md)）
- WHILE 敵が木の柵に触れている、1 秒ごとに敵の攻撃力のぶん柵が削れる（[enemy](enemy.md)）
- IF 敵が削りきった THEN 柵は倒れて通れるようになり、時間で起き上がる
- IF 柵が倒れている THEN 敵もプレイヤーも素通りする
- WHEN 柵のそばで Allmaity の「柵を壊す」を押した、いちばん近い柵が消える（[player](player.md)）

## やらないこと

- 遊んでいる最中の地形の生成。`FieldCreator` と `OutField` は中身が空のまま
- シード値からの復元。`RootDecode` も空
- 地図から場所のシーンを丸ごと作ること。地図が持つのは Cube の地形だけで、
  木・草・背景・出口・`Area` は場所のシーンに手で置く
- 木を切ること。スライスの説明には「木を切って素材が落ちる」とあるが、
  実装は時間で落ちるだけ

## 未決

- **遊んでいる最中の地形生成が無い。** シードは根源が持っているが、使う者が居ない。
  手で置いたシーンを使っている
- Root1 のシーンの Cube を、地図から組んだものに置き換えるか。置き換えれば地図が地形の正典になる
- Root2 と MainSite は地図にしていない。Root3 は地図ではなく、メニューの Tools/Roots/Build Root3 が
  水没したモールの組み立ての処理から作る（[D-022]）。手で直しても、組み直すと消える
- Root1 の奥の左端に、樹皮と岩の Cube が同じ場所に 2 つ重なっている。地図もそのまま写した
- Root1 の隠したままの地形（レーン B と C、壁）を残すか。地図には入れていない
- 枝以外が落ちてこない。`BranchFallSystem` は枝 1 種だけ
- 木の柵を壊しても何も戻らない。置き間違えたら、壊して枝 3 本を失う
- 耐久の戻りと倒れ方の値は仮。遊んで詰める
- 木の柵は奥行きに沿ってしか立てられない。横に沿った柵（奥と手前の行き来をふさぐ柵）を立てる手段が無い
- 落ちたものが消えない。拾わなければ増え続ける
- 木を切る操作を入れるか。入れるならスライスの説明が実態に追いつく
