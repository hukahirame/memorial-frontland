## 用語

- **場の範囲** — 場所ごとの、歩ける範囲。外へ出ると押し戻される（[player](player.md)）
- **地図** — 地形を文字で書いたファイル（下の「地図」）
- **木の柵** — 作業台で作り、持ち物から置く設置物（[craft](craft.md) / [inventory](inventory.md)）

## 受け入れ条件

### 落ちてくる枝

- 木の枝は切って落とすのではなく、時間をおいて勝手に落ちてくる
- 落ちる場所は場の範囲の中で毎回引き直す。上から落ちてくる
- 落ちているものは、触れると拾う（[inventory](inventory.md)）

### 木の柵を立てる

- 足元ではなく、主人公の絵が向いている側（右か左）に、いつも奥行きに沿って立つ。奥か手前へ歩いたあとでも、見えている向きの側に立つ
- 格子の線の上に、2 マスの長さで立つ。向いている側で、体から離れた最初の線に立つ。
  端が格子の点にそろうので、奥行きに沿って並べると端がつながる。格子は場所によらず同じ
- IF 立てる所に地面が無い、足元より高すぎるか低すぎる、ほかの柵（倒れた柵も）や動かない物（壁・岩・テント・見えない壁）に重なる
  THEN 立てられない。「ここには置けません」と出て、持ち物は減らない
- 端と角で触れ合うのは重なりとみなさない。敵と落とし物は重なっていても立てられ、柵が押しのける

### 木の柵が通すもの

- 敵を通さない。プレイヤーも歩いては通れないが、跳べば越えられる。敵は跳んでも越えられない
- 当たりは見た目とほぼ同じ大きさ。横から寄ると、見た目のすぐ手前で止まる
- 剣は素通りする。剣では削れず、止めも揺らしもしない

### 木の柵の耐久

- WHILE 敵が柵に触れている、間をおいて敵の攻撃力のぶん柵が削れる。削れるほど暗くなり、ぶつかられると揺れて音が鳴る
- 最後に削られてからしばらくたつと、耐久が少しずつ戻る
- WHEN 耐久が尽きた、根元を軸に、ぶつかった敵と反対の側へ倒れる。倒れているあいだは敵もプレイヤーも素通りでき、削られない
- 倒れた柵は寝たまま耐久が戻り、決まった割合を超えると起き上がって、また通さなくなる。
  削られても尽きていない柵は、その割合より下でも立っている
- WHEN 柵が起き上がった、重なっていた敵やプレイヤーは押し出される
- 柵の上に、残りの耐久をゲージで出す（数字は出さない）。いつも出し、カメラに正面を向ける。
  立っているあいだは緑、倒れているあいだは橙。少し透け、後ろの敵やプレイヤーが見える。
  削られると、減ったぶんが白く残ってから縮む。ゲージは核の候補のもの（[enemy](enemy.md)）より小さい

### 木の柵を壊す・残す

- WHEN 柵のそばに寄った、Allmaity ボタンに「柵を壊す」が出る。離れて手の届く柵が無くなると消える
- WHEN 「柵を壊す」を押した、手の届く柵のうちいちばん近いものが、膨らんでから縮んで消える。何も戻らない。倒れた柵も壊せる
- 置いた柵は、場所ごとに控えて置き直す（[scene](scene.md)）。向きと、残りの耐久と、倒れているかも戻す
- 場所を離れていたあいだも耐久は戻る。戻ったときに、離れていたぶん戻した耐久で置き直す。
  ゲームを閉じているあいだは数えない（[save](save.md)）

### 地形

- 根源1 の地形は地図と同じ形をしている
- 地図が持つのは見えている地形だけ

## 地図

場所のシーンと同じ名前で `Assets/_Project/Data/Fields/` に置く（Root1 なら `Root1.txt`）。
記号ごとの素材と当たりの大きさは `Assets/_Project/Data/Fields/FieldPalette.asset` にまとめる。
地図から地形を組むのはエディタの中だけ。

- 1 文字が 1 マス。マスの一辺は `cell` に書く
- 上の行ほど奥（z が大きい）、左の列ほど x が小さい。`origin` は左上のマスの中心（x z）
- `top 高さ` に続く行が 1 枚の層で、上面がその高さにそろう塊を並べる。空行で層が終わる
- `.` は何も置かない。同じ高さの層を 2 枚書くと、同じ場所に塊が 2 つ重なる
- どの層も行の数と幅をそろえる。そろわなければ、何行目かを添えて読むのを断る
- マスに乗らない塊は `piece 記号 x y z` の 1 行で書く。位置は中心で、向き（度）の x y z を足してよい
- `#` から行の終わりまでは注釈

```
cell 3
origin -22.5 2.5

top 0
ddddd
.ddd.

piece d 6.5 -2.05 -5.55 60 0 0
```

## やらないこと

- 遊んでいる最中の地形の生成と、シード値からの復元（[D-40]）
- 地図から場所のシーンを丸ごと作ること。地図が持つのは地形だけで、木・草・背景・出口は場所のシーンに置く
- 木を切ること。枝は時間で落ちるだけ

## 未決

- 地形を何から作るか（[D-40]）。いまは場所ごとに作り方が違い、根源1 のシーンは手で置いたままで、地図から組み直してはいない
- 根源1 の奥の左端に、塊が同じ場所に 2 つ重なっている。地図もそのまま写した
- 根源1 の隠したままの地形を残すか。地図には入れていない
- 枝以外が落ちてこない
- 落ちたものが消えない。拾わなければ増え続ける
- 木を切る操作を入れるか
- 木の柵を壊しても何も戻らない。置き間違えたら、壊して材料を失う
- 木の柵の耐久の戻りと倒れ方は仮。遊んで詰める
- 木の柵は奥行きに沿ってしか立てられない。横に沿った柵（奥と手前の行き来をふさぐ柵）を立てる手段が無い
