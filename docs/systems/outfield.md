## 用語

- **場の範囲** — 場所ごとの、歩ける範囲。外へ出ると押し戻される（[player](player.md)）
- **地図** — 地形を文字で書いたファイル（下の「地図」）
- **木の柵** — 作業台で作り、持ち物から置く設置物（[craft](craft.md) / [inventory](inventory.md)）

## 受け入れ条件

### 木の枝

- 木の枝は、時間をおいて勝手に落ちてくる
- 落ちる場所は、場の範囲の中で毎回引き直す
- 枝は上から落ちてくる

### 木の柵

| 状態 | きっかけ | 次の状態 | 起きること |
|---|---|---|---|
| — | 立てられる所で、持ち物から使った | 立っている | 持ち物が 1 個減る |
| — | 立てられない所で、持ち物から使った | — | 持ち物は減らない |
| 立っている | 敵が触れ続けた | 立っている | 間をおいて、敵の攻撃力のぶん削れる |
| 立っている | 最後に削られてからしばらくたった | 立っている | 耐久が少しずつ戻る |
| 立っている | 耐久が尽きた | 倒れている | 根元を軸に、ぶつかった敵と反対の側へ倒れる |
| 倒れている | 時間がたった | 倒れている | 寝たまま耐久が戻る |
| 倒れている | 耐久が決まった割合を超えた | 立っている | 起き上がり、重なっていた敵とプレイヤーを押し出す |
| 立っている・倒れている | 「柵を壊す」を押した | 無い | 膨らんでから縮んで消える。何も戻らない |

| 相手 | 立っている柵 | 倒れている柵 |
|---|---|---|
| 敵 | 通さない。跳んでも越えられない | 素通りする。削れない |
| プレイヤー | 歩いては通れない。跳べば越えられる | 素通りする |
| 剣 | 素通りする。削れず、止めも揺らしもしない | 素通りする |

- 当たりは、見た目とほぼ同じ大きさ
- 削られても尽きていない柵は、起き上がる割合より下でも立っている
- 「柵を壊す」で壊れるのは、手の届く柵のうちいちばん近いもの
- 置いた柵は、向き・残りの耐久・倒れているかも控えて置き直す（[scene](scene.md)）
- 場所を離れていたあいだも、耐久は戻る
- ゲームを閉じているあいだは、耐久が戻らない（[save](save.md)）

### 木の柵を立てる所

| 立てられない所 |
|---|
| 地面が無い |
| 足元より高すぎるか、低すぎる |
| ほかの柵に重なる。倒れた柵も数える |
| 動かない物（壁・岩・テント・見えない壁）に重なる |

- 柵は、主人公の絵が向いている側（右か左）に、奥行きに沿って立つ
- 立つ側は、歩いた向きではなく、見えている絵の向きで決まる
- 柵は、格子の線の上に 2 マスの長さで立つ
- 柵は、向いている側で、体から離れた最初の線に立つ
- 柵の端は、格子の点にそろう
- 格子は、場所によらず同じ
- 端と角で触れ合うのは、重なりとみなさない
- 敵と落とし物は、重なっていても立てられ、柵が押しのける

### 地形

- 根源1 の地形は、地図と同じ形をしている
- 地図が持つのは、見えている地形だけ

| 部品 | 出すもの | 出る条件 |

- 柵のゲージは、核の候補のもの（[enemy](enemy.md)）より小さい

## 地図

場所のシーンと同じ名前で `Assets/_Project/Data/Fields/` に置く（Root1 なら `Root1.txt`）。
記号ごとの素材と当たりの大きさは `Assets/_Project/Data/Fields/FieldPalette.asset` にまとめる。
地図から地形を組むのはエディタの中だけ。

- 1 文字が 1 マス。マスの一辺は `cell` に書く
- 上の行ほど奥（z が大きい）、左の列ほど x が小さい。`origin` は左上のマスの中心（x z）
- `top 高さ` に続く行が 1 枚の層で、上面がその高さにそろう塊を並べる。空行で層が終わる
- `.` は何も置かない。同じ高さの層を 2 枚書くと、同じ場所に塊が 2 つ重なる
- どの層も行の数と幅をそろえる。そろわなければ、何行目かを添えて読むのを断る
- マスに乗らない塊は `piece 記号 x y z` の 1 行で書く。位置は中心で、向き（度）の x y z を足してよい
- `#` から行の終わりまでは注釈

```
cell 3
origin -22.5 2.5

top 0
ddddd
.ddd.

piece d 6.5 -2.05 -5.55 60 0 0
```

## やらないこと

- 遊んでいる最中の地形の生成と、シード値からの復元（[D-40]）
- 地図から場所のシーンを丸ごと作ること。地図が持つのは地形だけで、木・草・背景・出口は場所のシーンに置く
- 木を切ること。枝は時間で落ちるだけ

## 未決

- 地形を何から作るか（[D-40]）。いまは場所ごとに作り方が違い、根源1 のシーンは手で置いたままで、地図から組み直してはいない
- 根源1 の奥の左端に、塊が同じ場所に 2 つ重なっている。地図もそのまま写した
- 根源1 の隠したままの地形を残すか。地図には入れていない
- 枝以外が落ちてこない
- 落ちたものが消えない。拾わなければ増え続ける
- 木を切る操作を入れるか
- 木の柵を壊しても何も戻らない。置き間違えたら、壊して材料を失う
- 木の柵の耐久の戻りと倒れ方は仮。遊んで詰める
- 木の柵は奥行きに沿ってしか立てられない。横に沿った柵（奥と手前の行き来をふさぐ柵）を立てる手段が無い
