## 用語

- **調査** — 根源の核（[roots](roots.md)）を壊し、生きてその根源を出るクエスト
- **決壊** — 氾濫した根源に出るクエスト。核を壊したあと敵を決まった数倒し、生きてその根源を出る
- **サブ** — その根源で敵を倒すクエスト
- **共通** — どの場所でも進むクエスト
- **対象の根源** — そのクエストが出ている根源
- **達成** — 壊す・倒す目標を満たしたこと。調査は核を壊したとき、決壊は敵を倒しきったとき
- **成功** — 調査か決壊を達成したまま、対象の根源を生きて出たこと

## 受け入れ条件

### クエストの種類

| 種類 | ID の先頭 | 出るとき | 出さない場合 | 受注 | 進む場所 | 達成したとき |
|---|---|---|---|---|---|---|
| 調査 | X | 保存なしで始めたとき、夜明け（[day](day.md)） | その根源に調査か決壊がある | 要る | 対象の根源の中 | 一覧に残り、成功を待つ |
| 決壊 | Y | 根源が氾濫したとき（[roots](roots.md)） | その根源に決壊がある | 要る | 対象の根源の中 | 一覧に残り、成功を待つ |
| サブ | S | 保存なしで始めたとき、夜明け | その根源にサブが残っている | 要らない | 対象の根源の中 | その場で報酬を払い、一覧から消える |
| 共通 | C | 出ない | — | 要らない | どの場所でも | — |

- 出すのは、1 回につき根源ごとに 1 本
- ID の先頭の文字は変えない（[save](save.md)）
- WHEN 保存から始めた、保存したクエストと受注を戻す（[save](save.md)）
- WHEN 保存から始めた、保存のあとで足した根源に調査とサブを出す
- WHEN 対象を倒した、進む場所に合うクエストの進みが 1 増える（[enemy](enemy.md)）

### 調査と決壊

| 状態 | きっかけ | 次の状態 | 起きること |
|---|---|---|---|
| 未受注 | 対象の根源の外で枠を押した | 受注中 | — |
| 受注中 | 対象の根源の外で枠をもう一度押した | 未受注 | — |
| 受注中 | 対象の根源に入った | クエスト中 | — |
| クエスト中 | 対象の根源を出た | 受注中 | — |
| クエスト中 | 核を壊した | 破壊済み | 大きい文字で「破壊」と出す。調査はここで達成 |
| 破壊済み（決壊） | 核を壊したあとの敵を倒しきった | 討伐済み | 大きい文字で「討伐」と出す。決壊はここで達成 |
| 破壊済み（決壊） | 対象の根源を出た | 破壊済み | 倒した数が残る。入り直しても核は壊し直さない |
| 達成 | 対象の根源を生きて出た | 成功 | 着いた先ですぐ報酬を受け取る。一覧から消え、受注が空く |
| クエスト中・破壊済み・討伐済み | 対象の根源の中で倒れた | 受注中 | 失敗になり、進みが 0 に戻る（[player](player.md)） |

- 受注できるのは全体で 1 本
- 進むのは受注中の 1 本だけ
- IF 受注せずに核を壊した THEN 敵は湧くが、どのクエストも進まない
- 決壊で数える敵の種類は問わない
- 対象の根源の外で倒れても失敗にならない
- WHEN 成功が決まった、その時点で達成済みのクエストすべての報酬を受け取る

### 報酬

| 報酬 | 行き先 |
|---|---|
| コイン | 所持金（[wallet](wallet.md)） |
| 攻略度 | 対象の根源（[roots](roots.md)） |
| 品 | 持ち物へ 1 個ずつ（[inventory](inventory.md)） |

- 調査と決壊のコインは、対象の根源の危険度で決まる
- 決壊のコインは調査より多い
- IF 品が持ち物に入りきらない THEN 入らない分は受け取れない

### 画面

| 部品 | 出すもの | 出る条件 |
|---|---|---|
| 一覧の枠 | 目的と報酬の表示名 | いつも |
| 一覧の枠 | 強調と、状態の札（受注中・クエスト中・達成済み） | 受注中の枠 |
| 一覧の枠 | 「ほかを受注中」 | ほかの調査か決壊を受注しているあいだの、調査と決壊の枠 |
| 受注中の札 | 1 行めに状態・根源の名前・種類、2 行めに目的 | 調査か決壊を受注しているあいだ |
| 中くらいの文字 | 払った報酬 | サブを達成したとき |
| 大きい文字「成功」 | 払った報酬 | 成功して根源へ出たとき |
| 報酬 UI | 受け取った報酬 | 成功して拠点へ出たとき |
| 報酬 UI | 失敗 | 失敗のあと拠点に戻ったとき |
| 知らせ | 受け取った品の表示名 | 品を受け取ったとき |

受注中の札の 2 行め。

| 状態 | 調査 | 決壊 |
|---|---|---|
| 受注中・クエスト中 | 核を壊す | 核を壊す |
| 破壊済み | 生きて根源を出る | 敵の討伐と、倒した数 |
| 討伐済み | — | 生きて根源を出る |

- 受注中の札は、画面の左上の体力の下に出る
- 受注中の札は押せず、下のボタンを隠さない
- 報酬 UI は時間を止めない
- 報酬 UI は閉じるまで残る

## やらないこと

- 期限。日をまたいでも消えない
- 一覧に 1 つの根源で 5 本以上を出すこと
