## デフォルトと違う点

- 調査と決壊で壊すのは、根源の中にある**核**（[roots](roots.md)）。「拠点」はプレイヤーの家（MainSite）だけを指す
- クエストの種別は ID の先頭 1 文字に埋まっている。調査 X、決壊 Y、サブ S、共通 C。
  保存データと GameObject の名前に出るので、この文字は変えられない
- 番号は空きを前から詰めて採る。消したあとに同じ番号が再利用される
- 受注できるのは 1 本だけ。`ordered_id` は 1 つしか持たない
- 受けるのも解除するのも、対象の根源の外でだけできる。拠点でも、ほかの根源からでもよい
- 受けたクエストは、対象の根源に入ったときに始まる。通り道の根源では始まらない
- 根源へは受注にかかわらず入れる（[scene](scene.md)）。受けずに核を壊すと、湧きだけ起きて何も達成しない
- 保存が無いまま始めたときに、根源ごとに調査とサブを 1 本ずつ作る。夜明けの発行は保留を挟むので、
  これが無いと 2 回目の夜明け（始めてから約 2 分半）まで受けるものが無い。保存があれば、保存したクエストと受注を戻し、
  保存のあとで足した根源にだけ調査とサブを作る（[save](save.md)）
- 決壊は、氾濫した根源に出る。核を壊したあと、敵を 5 体倒してから生きて根源を出る。報酬は調査の倍。
  数えるのは核を壊したあとに倒した敵だけで、種類は問わない。倒しきる前に根源を出ても進みは残り、入り直して続きを倒せばよい
  （核は入るたびに元に戻るが、壊し直さなくてよい）
- 調査と決壊の報酬のコインは、対象の根源の危険度で決まる。調査なら危険度の 1/10 で、
  危険度 1000 の根源は 100、2000 の根源は 200
- サブは 1 つの根源に 1 本まで。残っていれば夜明けにも足さない。足すと 1 体倒すたびに両方が進み、2 本ぶん払う
- 進捗の伸び方が種別で違う
  - 調査と決壊は、受注中の 1 本だけが、対象の根源の中でだけ進む。通り道の根源で核を壊しても進まない
  - サブは、その根源のシーンに居る間だけ進む
  - 共通は、どのシーンでも進む
- 調査と決壊は、達成しても自動では片付かない。成功が決まって受け取るまで残る
- 成功で受け取るのは、その時点で達成済みのクエストすべて。サブは達成したときに払って一覧から消えるので、ここには入らない
- 対象の根源を出る前にその中で倒れると、達成していても失敗になる。進捗は 0 に戻るが受注は残るので、もう一度挑める。
  対象の根源の外で倒れても失敗にはならない
- そのため調査と決壊は、達成した時点では達成と出さない。調査は核を壊したときに大きい文字で「破壊」と出し、生きて根源を出るよう促す。
  決壊は核を壊したときに「破壊」と出して敵を倒すよう促し、倒しきったときに「討伐」と出して生きて根源を出るよう促す
- 達成したまま対象の根源を生きて出ると、成功が決まり、着いた先ですぐ報酬を受け取る。受注の枠も空く。
  拠点へ出たなら報酬 UI で、根源へ出たなら大きい文字の「成功」に払った分を添えて渡す。
  報酬 UI は時間を止めず閉じるまで残るので、敵の居る根源では開かない
- サブは達成したその場で払い、払った分を添えて中くらいの文字で知らせる。一覧からは消え、次の夜明けに新しいサブが出る
- 目的と報酬は表示名で出す。討伐の対象は倒した敵の GameObject の名前と突き合わせるので、クエストには名前のまま持つ
- 受注中の枠をもう一度押すと解除できる
- 受注中の枠は、縁を金に、地を暖かい色にし、状態（受注中・クエスト中・達成済み）を赤いリボンに白い字で載せて目立たせる。
  ほかの根源の調査か決壊を受けているあいだ、受けていない調査と決壊の枠は状態に灰色で「ほかを受注中」と出る
- 調査か決壊を受注しているあいだは、画面の左上（体力の下）に小さな札で出す。1 行めが状態と「根源の名前」調査（決壊）クエスト、
  2 行めが目的。状態は、対象の根源の外では受注中、中ではクエスト中、核を壊したあとは破壊済み。調査は目的も「生きて根源を出る」に変わる。
  決壊は目的が「敵を5体討伐する」に変わって倒した数（2/5 など）を添え、倒しきると討伐済みと「生きて根源を出る」になる。
  札の幅は文字の長さに合わせる。札は押せず、下のボタンを隠さない（`QuestTracker`）

## 相互作用

- WHEN 夜明け（5時）、根源ごとに調査とサブを出す（[day](day.md)）
- IF その根源に調査か決壊が既にある THEN 調査は出さない。無ければ 1 度見送ってから出す
- IF その根源にサブが残っている THEN サブは足さない。調査が残っているかにはかかわらない
- WHEN 根源が氾濫した、その根源に決壊を出す（[roots](roots.md)）
- IF その根源に決壊が既にある THEN 足さない
- WHEN 対象を倒した、条件に合うクエストの進捗が 1 増える（[enemy](enemy.md)）
- WHEN サブを達成した、その場で報酬を受け取る
- WHEN 調査か決壊を達成したまま対象の根源を出た、成功が決まり、着いた先で報酬を受け取る（[scene](scene.md)）
- IF 受けたクエストの対象の根源に居る THEN 拠点への近道が使えない。核を壊したあとも歩いて出る（[scene](scene.md)）
- WHEN 報酬を受け取った、`coin` は所持金へ、`progress` は根源の攻略度へ入る。攻略度は 100 で止まる
  （[wallet](wallet.md) / [roots](roots.md)）。それ以外はアイテム ID として、個数ぶん 1 個ずつ持ち物へ入れ、原簿の表示名で知らせる。
  入りきらない分は受け取れない（[inventory](inventory.md)）
- WHEN 受けているクエストの根源で死亡した、拠点に戻ったときに報酬 UI が失敗として出る。
  ほかの場所で死亡しても出ない（[player](player.md)）
