## 用語

- **調査** — 根源の核（[roots](roots.md)）を壊し、生きてその根源を出るクエスト
- **決壊** — 氾濫した根源に出るクエスト。核を壊したあと敵を決まった数倒し、生きてその根源を出る
- **サブ** — その根源で敵を倒すクエスト
- **共通** — どの場所でも進むクエスト
- **達成** — クエストの目的を満たしたこと
- **成功** — 調査か決壊を達成したまま、対象の根源を生きて出たこと。ここで報酬が決まる

## 受け入れ条件

### 受注

- 受注できるのは 1 本だけ
- 受けるのも解除するのも、対象の根源の外でだけできる。拠点でも、ほかの根源からでもよい。受注中の枠をもう一度押すと解除できる
- 受けたクエストは、対象の根源に入ったときに始まる。通り道の根源では始まらない
- 根源へは受注にかかわらず入れる（[scene](scene.md)）。受けずに核を壊すと、湧きだけ起きて何も達成しない

### 発行

- 保存が無いまま始めたときに、根源ごとに調査とサブを 1 本ずつ作る。保存があれば保存したクエストと受注を戻し、
  保存のあとで足した根源にだけ調査とサブを作る（[save](save.md)）
- WHEN 夜明け、根源ごとに調査とサブを出す（[day](day.md)）
- IF その根源に調査か決壊が既にある THEN 調査は出さない
- IF その根源にサブが残っている THEN サブは足さない。調査が残っているかにはかかわらない
- WHEN 根源が氾濫した、その根源に決壊を出す（[roots](roots.md)）。既にあれば足さない
- クエストの種別を表す ID の先頭の文字（調査 X、決壊 Y、サブ S、共通 C）は変えない。保存に出ている

### 進みと達成

- 調査と決壊は、受注中の 1 本だけが、対象の根源の中でだけ進む。通り道の根源で核を壊しても進まない
- サブは、その根源に居る間だけ進む。共通は、どの場所でも進む
- WHEN 対象を倒した、条件に合うクエストの進捗が 1 増える（[enemy](enemy.md)）
- 決壊で数えるのは、核を壊したあとに倒した敵だけ。種類は問わない。倒しきる前に根源を出ても進みは残り、
  入り直して続きを倒せばよい（核は壊し直さなくてよい）
- 調査と決壊は、達成した時点では達成と出さない。調査は核を壊したときに大きい文字で「破壊」と出し、生きて根源を出るよう促す。
  決壊は核を壊したときに「破壊」と出して敵を倒すよう促し、倒しきったときに「討伐」と出して生きて根源を出るよう促す
- 調査と決壊は、達成しても自動では片付かない。成功が決まって受け取るまで残る
- WHEN サブを達成した、その場で報酬を払い、払った分を添えて中くらいの文字で知らせる。一覧からは消える

### 成功と失敗

- WHEN 調査か決壊を達成したまま対象の根源を生きて出た、成功が決まり、着いた先ですぐ報酬を受け取る。受注の枠も空く。
  受け取るのは、その時点で達成済みのクエストすべて
- 拠点へ出たなら報酬 UI で、根源へ出たなら大きい文字の「成功」に払った分を添えて渡す。
  報酬 UI は時間を止めず、閉じるまで残る。根源では開かない
- WHEN 対象の根源を出る前にその中で倒れた、達成していても失敗になる。進捗は 0 に戻るが受注は残り、もう一度挑める。
  拠点に戻ったときに報酬 UI が失敗として出る（[player](player.md)）
- 対象の根源の外で倒れても失敗にはならない

### 報酬

- 調査と決壊の報酬のコインは、対象の根源の危険度で決まる。決壊は調査より多い
- WHEN 報酬を受け取った、コインは所持金へ（[wallet](wallet.md)）、攻略度のぶんは根源へ入る（[roots](roots.md)）。
  品は 1 個ずつ持ち物へ入れ、原簿の表示名で知らせる。入りきらない分は受け取れない（[inventory](inventory.md)）

### 画面

- 目的と報酬は表示名で出す
- 受注中の枠は目立たせ、状態（受注中・クエスト中・達成済み）を札で載せる。
  ほかの根源の調査か決壊を受けているあいだ、受けていない調査と決壊の枠には「ほかを受注中」と出る
- 調査か決壊を受注しているあいだは、画面の左上（体力の下）に小さな札で出す。1 行めが状態と根源の名前とクエストの種別、2 行めが目的。
  状態は、対象の根源の外では受注中、中ではクエスト中、核を壊したあとは破壊済み。調査は目的も「生きて根源を出る」に変わる。
  決壊は目的が敵の討伐に変わって倒した数を添え、倒しきると討伐済みと「生きて根源を出る」になる。
  札は押せず、下のボタンを隠さない

## やらないこと

- 期限。日をまたいでも消えない
- 一覧で 5 本以上を出すこと。1 つの根源につき 4 本まで

## 未決

- 共通クエストが作られない
- 報酬の品が持ち物に入りきらないとき、入らない分は消える。落とすか、受け取りを待たせるか。持ち物が埋まったときの逃げ道（[D-34]）に従う。
  いまは品を報酬にするクエストが無い
