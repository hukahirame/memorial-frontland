## デフォルトと違う点

- クエストの種別は ID の先頭 1 文字に埋まっている。調査 X、決壊 Y、サブ S、共通 C。
  保存データと GameObject の名前に出るので、この文字は変えられない
- 番号は空きを前から詰めて採る。消したあとに同じ番号が再利用される
- 受注できるのは 1 本だけ。`ordered_id` は 1 つしか持たない
- 受けるのも解除するのも、対象の根源の外でだけできる。拠点でも、ほかの根源からでもよい
- 受けたクエストは、対象の根源に入ったときに始まる。通り道の根源では始まらない
- 根源へは受注にかかわらず入れる（[scene](scene.md)）。受けずに拠点を壊すと、湧きだけ起きて何も達成しない
- 始めたときに、根源ごとに調査とサブを 1 本ずつ作る。夜明けの発行は保留を挟むので、
  これが無いと 2 回目の夜明け（始めてから約 2 分半）まで受けるものが無い
- サブは 1 つの根源に 1 本まで。残っていれば夜明けにも足さない。足すと 1 体倒すたびに両方が進み、2 本ぶん払う
- 進捗の伸び方が種別で違う
  - 調査と決壊は、受注中の 1 本だけ進む
  - サブは、その根源のシーンに居る間だけ進む
  - 共通は、どのシーンでも進む
- 達成しても自動では片付かない。成功が決まって受け取るまで残る
- 受け取るのは、その時点で達成済みのクエストすべて。他の根源のサブも一緒に払い、報酬 UI にもすべて出す
- 対象の根源を出る前にその中で倒れると、達成していても失敗になる。進捗は 0 に戻るが受注は残るので、もう一度挑める。
  対象の根源の外で倒れても失敗にはならない
- そのため調査と決壊は、拠点を壊した時点では達成と出さない。大きい文字で「破壊」と出し、生きて根源を出るよう促す
- 達成したまま対象の根源を生きて出ると、成功が決まり、着いた先ですぐ報酬を受け取る。受注の枠も空く。
  拠点へ出たなら報酬 UI で、根源へ出たなら大きい文字の「成功」に払った分を添えて渡す。
  報酬 UI は時間を止めず閉じるまで残るので、敵の居る根源では開かない
- サブは達成した 1 回だけ、中くらいの文字で知らせる。掲示板の枠にも「達成済み」と出る。払うのは、
  次に調査か決壊の成功を受け取るとき
- 目的と報酬は表示名で出す。討伐の対象は倒した敵の GameObject の名前と突き合わせるので、クエストには名前のまま持つ
- 受注済みの枠をもう一度押すと解除できる

## 相互作用

- WHEN 夜明け（5時）、調査とサブのクエストが根源ごとに発行される（[day](day.md)）
- IF その根源に調査か決壊が既にある THEN 発行しない
- IF その根源にサブが残っている THEN サブだけ足さない
- WHEN 対象を倒した、条件に合うクエストの進捗が 1 増える（[enemy](enemy.md)）
- WHEN 調査か決壊を達成したまま対象の根源を出た、成功が決まり、着いた先で報酬を受け取る（[scene](scene.md)）
- WHEN 報酬を受け取った、`coin` は所持金へ、`progress` は根源の攻略度へ入る
  （[wallet](wallet.md) / [roots](roots.md)）
- WHEN 受けているクエストの根源で死亡した、拠点に戻ったときに報酬 UI が失敗として出る。
  ほかの場所で死亡しても出ない（[player](player.md)）

## やらないこと

- 期限。日をまたいでも消えない
- 一覧で 5 本以上を出すこと。1 つの根源につき 4 本まで

## 未決

- 決壊クエストを発行する契機が無い。種別も表示も見出しもあるが、誰も作らない。
  もとは調査より危険も報酬も大きい形式として置いたもの。氾濫と結びつけるかは決めていない
- 共通クエストも作られない
- 始めたときの調査は、Root2 だけ報酬が 200 コイン。夜明けに出るものは 100
- サブの報酬を払うのが、次に調査か決壊の成功を受け取るときでよいか。サブだけ達成して帰っても何も出ない
- クエストが保存されない。再起動で受注状態ごと消える
- 報酬のアイテム。`Reward.Kind` は任意のアイテム ID を取れるが、使われていない。
  入れると `RewardUI.Grant` が自分の子に無い `Inventory` を探して例外になる
