## デフォルトと違う点

- 追加は前のスロットから探し、削除は後ろのスロットから減らす
- 同じアイテムが複数のスロットに分かれる。所持数は合計で数える
- 空きスロットは ItemId が空文字。null では表さない
- 俊敏の首飾りは、装備ではなく**持っているだけ**で移動速度が上がる
- 剛力のペンダントも、持っているだけで攻撃力が上がる。原簿の攻撃力の列は、装備しない品では持っているだけで足す値として読む。
  足すのは振って当てるたびで、持ち物の今の中身から数える
- 原簿に無いアイテムを拾うと、最大ストック 0 のスロットが出来て積めなくなる
- 倒れている間と場所を移っている間は、持ち物を使えない。食べるのも装備も設置も
- 装備している武器の入った枠の左上に「装備中」の札を出す。同じ武器が 2 つあれば前の枠に出す。
  持ち物が変わったときと、装備を替えたときに付け直す（`PlayerInventory.MarkEquipped`）
- スロットは 15。箱は 5 つずつ 3 段に並ぶ。場に並べた箱は 10 個（2 段）で、足りない段は起動時に 1 段上の箱を写して下に足す。
  段の間は場の 1 段目と 2 段目の間と同じ。スロット数を超える箱は起動時に隠す
- スロット数ぶんの箱の後ろに、起動時に受け皿を敷く。空いた箱も見える。
  受け皿は箱より前の並びに置くので、箱を並びの番号で引くときの数え始め（`CHILDPLUS`）が 1 つずれる

## 相互作用

- WHILE 俊敏の首飾りを所持、移動速度 +0.3。2 つ持てば +0.6
- WHILE 剛力のペンダントを所持、攻撃力 +10。2 つ持てば +20（[player](player.md)）
- WHEN 使い道が「装備」のアイテムを使った、武器が置き換わる（[player](player.md)）
- WHEN 使い道が「食べる」のアイテムを使った、体力が回復して 1 個減る（[player](player.md)）
- WHEN 使い道が「設置」のアイテムを使った、足元に実体が湧いて 1 個減る。木の柵だけは足元ではなく、
  主人公の絵が向いている側に、奥行きに沿って立つ（[outfield](outfield.md)）
- IF 木の柵を立てられる所が無い THEN 「ここには置けません」と出て、減らない
- WHEN 落ちているものに触れた、スロットに空きがあれば拾う（[outfield](outfield.md)）
- IF スロットが埋まっている THEN 拾わない。落ちたまま残る。空いたあとは、触れたままでも拾う
- WHEN 中身が変わった、交換画面の材料の所持数を書き直す（[craft](craft.md)）

## やらないこと

- スロットの並べ替えとスロット間の移動
- 耐久値をスロットに持つこと。`ItemSlot` は ItemId と個数と上限だけ。
  拾うときに渡される耐久値は UI の Slider にしか入らず、保存もされない
- 所持の上限をスロット数以外で決めること
