## デフォルトと違う点

- 追加は前のスロットから探し、削除は後ろのスロットから減らす
- 同じアイテムが複数のスロットに分かれる。所持数は合計で数える
- 空きスロットは ItemId が空文字。null では表さない
- 俊敏の首飾りは、装備ではなく**持っているだけ**で移動速度が上がる
- 原簿に無いアイテムを拾うと、最大ストック 0 のスロットが出来て積めなくなる

## 相互作用

- WHILE 俊敏の首飾りを所持、移動速度 +0.3。2 つ持てば +0.6
- WHEN 使い道が「装備」のアイテムを使った、武器が置き換わる（[player](player.md)）
- WHEN 使い道が「食べる」のアイテムを使った、体力が回復して 1 個減る（[player](player.md)）
- WHEN 使い道が「設置」のアイテムを使った、足元に実体が湧いて 1 個減る
- WHEN 落ちているものに触れた、スロットに空きがあれば拾う（[outfield](outfield.md)）
- IF スロットが埋まっている THEN 拾わない。落ちたまま残る

## やらないこと

- スロットの並べ替えとスロット間の移動。`Inventbutton` の交換処理はコメントのまま
- 耐久値をスロットに持つこと。`ItemSlot` は ItemId と個数と上限だけ。
  拾うときに渡される耐久値は UI の Slider にしか入らず、保存もされない
- 所持の上限をスロット数以外で決めること
