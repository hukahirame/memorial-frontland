## デフォルトと違う点

### 湧き

- 湧きを見送る条件が 2 つあり、順に引く。抑制が決まった時点で以降は引かない
  - 根源の攻略度が 50 以上なら、50% で見送る
  - 既に居る敵 1 体につき 3% ずつ見送る確率が上がる
- 根源の無いシーンでは攻略度による抑制が掛からない。混み具合だけを見る
- 攻略度が 30 以上の根源では、湧いた敵の体力が 2 割減る

### 行動

- 待機 60%、移動 20%、跳躍 20% で選ぶ
- 選んだ行動を続ける秒数も引く。待機 1.5〜2 秒、移動 0.5〜2.5 秒、跳躍は 1.2 秒で固定
- 跳躍だけ幅を持たせない。着地を待つため
- 徘徊先は場の範囲で丸められる。外へは行かない

### 落とすもの

- 必ず落ちるものと、割合で落ちるものを足す
- 割合は敵の prefab ごとに持つ。敵の種類で変えられる

### 当たり

- 体力の正典は Domain の `Health`。Slider は表示
- ダメージを与える側は `IDamageable` 越しにしか触らない。相手の中身を知らない

## 相互作用

- WHEN 敵を 1 体倒した、根源の蓄積値が 3 減る（[roots](roots.md)）
- WHEN 敵を 1 体倒した、対象の合うクエストの進捗が 1 増える（[quest](quest.md)）
- WHEN 敵を 1 体倒した、落とすものが決まって地面に出る
- WHEN 根源が氾濫した、敵が 5 体まとめて湧く（[roots](roots.md)）
- WHEN 敵が高さ -10 より下へ落ちた、場外として扱う
- WHEN 拠点や候補を攻撃した、その耐久が減る。0 で壊れる

## 調整値

いずれも ScriptableObject に出ていない。`tune` で触れない。

| 値 | 居場所 |
|---|---|
| 抑制の攻略度 50、確率 50% | `SpawnRule.SuppressProgress` / `SuppressPercent` |
| 混み具合 1 体あたり 3% | `SpawnRule.CrowdPercentPerEnemy` |
| 弱体化の攻略度 30、割合 0.2 | `SpawnRule.WeakenProgress` / `WeakenRatio` |
| 討伐時の鎮静 3 | `SpawnRule.CalmPerDefeat` |
| 行動の割合 60 / 20 / 残り | `ActionRule.WaitPercent` / `MovePercent` |
| 行動の秒数 | `ActionRule` の定数 |
| 場外の高さ -10 | `FallRule.OutOfFieldY` |
| 敵ごとの落とすものと割合 | 敵 prefab の `DropChance` |
| 敵の攻撃力 | 敵 prefab の `Slime.power` |
