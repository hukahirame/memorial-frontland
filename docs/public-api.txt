# Domain が使う側へ見せている型とメンバ。1行が1つの面。
# 使う側が通らなくなる変化は、既存の行が消えるか書き換わる形で出る。
# 足しただけなら行が増えるだけ。ただし既存の型に abstract の行が増えると、実装する側が壊れる。
#
# 型ごとに、型の行、基底の行、メンバの行の順に並ぶ。private と internal は入らない。
