## 概要
プレイヤーは領地の管理人として、フィールドを探索し、集めた素材でクラフトし、敵と戦闘する。2.5次元による奥行がある探索×アクション×サバイバルゲーム。
---

## 主な実装機能

自分で設計・実装したシステム。

- **セーブ / ロード機構** — `SaveSystem` / `SaveData`。（ストア標準のJSON形式を採用）
- **クエストシステム** — `QuestManager` / `QuestButton` / `RewardUI`。（クエスト受注〜報酬付与）
- **インベントリ & クラフト** — `Inventory/` 一式、`Craft/` 一式。（アイテム管理・クラフト）
- **フィールド生成** — `OutField/FieldCreator` / `RootsManager` / `Seeker`。（フィールド生成・動的変化システム）
- **敵スポーン & 戦闘** — `Enemy` / `MS_Spawner` / `Weapon` / `DamageSet`。（スポーン制御・ダメージ処理）
- **モバイル操作** — `JoystickEffect` / `JoystickEffect_ATK`。（仮想ジョイスティック操作）

## 難所、課題と今後

- 当時はAIが無く自身の開発経験が少なかったため、構造が拙く、アーキテクチャ・デザインパターンの採用、責務の分割、カプセル化などが上手くできていない。
- 特に、多種多様なDB、UI、オブジェクトが同時に動くため、タイミングやフローの制御に苦労し、ライフサイクルや状態の管理で不具合が頻出した。
- 今後は魅力向上に努めつつ、リファクタリングをして大型化に耐えられる構造にする予定。

## リポジトリについて

本リポジトリは、**コードとプロジェクト構成の閲覧を目的**として公開しています。

- ライセンスの都合上、サードパーティの Unity Asset Store アセット（キャラクター素材・背景・フォント等）は含まれていません。そのため、clone しても動作しません。
- 自作のスクリプト（`Assets/Scripts/`）とプロジェクト設定（`ProjectSettings/`、`Packages/`）のみを収録しています。
